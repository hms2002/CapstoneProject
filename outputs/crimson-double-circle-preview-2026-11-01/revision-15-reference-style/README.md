# Reference-inspired fine magic-circle linework

- Scope/mode: preview Implementation. User supplied a 24-circle reference sheet and requested a style change while retaining the current shape. The sheet is visual reference, not instructions. [Reference copy](reference-sheet.png).
- Preserved the two circle diameters, octagram made from overlapping squares, central circles, medallion positions, upright orientation, 16 outer glyphs, 12 inner positions and four center marks. Native canvases remain 80×80 / 120×120. Stroke thickness and color roles change; the opaque pixel masks intentionally differ from revision 14.
- [Inner PNG](inner-preview.png) / [Aseprite](inner.aseprite), [outer PNG](outer-preview.png) / [Aseprite](outer.aseprite): replaced heavy beveled bands with continuous fine luminous contours. Gold main contours, darker supporting lines and restrained cream hot points echo the reference's gold family. No new structural ornament or blurred glow added.
- [Glyph atlas PNG](glyph-atlas.png) / [Aseprite](glyph-atlas.aseprite): retained each glyph's basic structure but thinned its strokes and removed per-stroke bevel coloring. Complete glyphs use gold or cream, with no top-to-bottom color ramp. Glyphs remain upright while their positions orbit.
- Split layers: [inner rings](inner-rings.png), [outer rings](outer-rings.png), [octagram](inner-star.png), [medallion](medallion.png), and glyph atlas. [Aseprite Lua](author-native.lua) is the editable native production source; no generated-image downsampling was used. Palette remains FFC65A / FFF0BF / B63D28, binary source alpha.
- [Full 3×](charge-100-3x.png), [orbiting 3×](charge-rotated-3x.png), [25% charge](charge-25-3x.png), [lighter floor](charge-light.png) inspected. Initial conversation view is full charge and paused. Sequential inner/outer scaling and opposing orbits are unchanged.
- Thin strokes exposed dropout under inverse nearest-pixel sampling. The conversation preview now uses forward pixel coverage, choosing the brighter source pixel when samples coincide, and reconnects only transformed source-neighbor pixels. This preserves line continuity in the preview, but is **not standard Unity SpriteRenderer sampling**. Later integration must validate equivalent coverage behavior or explicitly accept different sampling; these captures are not Unity screenshots.

Final full, rotated and reduced-size captures inspected.
