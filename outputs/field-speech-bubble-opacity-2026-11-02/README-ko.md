# NPC 위의 말풍선 — 반투명과 불투명 비교

가능하다. 현재 PNG의 색 있는 픽셀은 모두 불투명하며, 배경이 비치는 원인은 PNG가 아니라 테마 배경색의 알파다. 이미지·음영·직접 그린 선·자동 외곽선은 유지하면서 배경 알파를 1로 바꾸면 된다.

수정 자체는 게임에 직접 적용하는 편이 빠르다. 바뀌는 설정이 작기 때문이다. 다만 이번 목적은 NPC 위에서 배경과 함께 보았을 때의 가독성 판단이므로, 미리보기에서 한 번 비교한 뒤 적용하는 흐름을 권한다. 이번 작업은 조사와 시각 자료만 만들었고 게임 설정을 바꾸지 않았다.

## 결과와 적용 범위 제안

기본 말풍선의 배경 알파는 `SpeechBubblePrefab.prefab`의 `defaultFillColor.a = 0.52`다. 마녀는 `WitchBossSpeechData.asset`의 사용자 지정 `bubbleTheme.fillColor.a ≈ 0.392`를 사용한다. 슬라임·드래곤·마왕 테마는 이미 1이다. 따라서 현재 공용 말풍선을 불투명하게 적용하려면 기본 배경과 마녀 테마의 두 알파값을 1로 맞추는 것이 좁은 수정 범위다.

기존 런 특수 NPC 데이터에 남아 있는 알파 0.52는 `useCustomColors: 0`인 상태여서 공용 프리팹 기본 배경색을 따른다. 해당 legacy 데이터나 runtime C# 기본값을 일괄 수정할 필요는 없다. 현재 저장된 프리팹을 사용하는 흐름이 기준이다.

현재와 불투명의 차이는 배경이 비치느냐에 있다. 불투명에서는 흰 채움과 아래 RGB 음영이 안정적으로 보이고, 원래 알파 모양 바깥의 투명 영역은 유지된다. 배경 투명도만 없애는 범위이므로 등장·퇴장의 CanvasGroup 페이드와는 구분한다.

## 실제 자산과 미리보기의 차이

- 현재 적용된 첨부 PNG, 실제 SpeechBubblePrefab의 Image/TMP/HorizontalLayoutGroup/ContentSizeFitter 계층과 기존 셰이더·머티리얼을 사용했다. texture influence 1, 자동 외곽선 두께 0.52, 9분할을 유지했다.
- NPC는 RunMerchantGroup이 사용하는 `Merchant 1.png` 월드 스프라이트다. 기존의 `Visual` 상대 위치와 말풍선 offset 0.3/0.7을 참고해 정적으로 배치했다. 문장은 상인 프리팹에 있는 “골드가 부족하군.”을 사용했다.
- 한국어 가독성 확인을 위해 프로젝트의 Galmuri9 픽셀 폰트를 선택했다. 검증용 프리팹 복사본의 폰트 참조만 이 자산으로 바꿨으며, localization 이벤트와 전체 SpeechBubble 런타임은 실행하지 않았다. 게임 원본 폰트 설정은 그대로다.
- 배경은 SlimeBossLevelSet과 GrandHall_Tilemap의 실제 타일 조각을 반복한 비교용 배치다. 가독성 차이를 보기 위한 간단한 구성이고 실제 게임 씬을 촬영한 것은 아니다. 두 번째 배경은 일부러 무늬가 강한 타일을 사용했다.
- 마녀 색상 비교는 같은 상인 위에 마녀 테마를 임시 대입한 참고 장면이며 상인의 실제 대사 테마 변경이 아니다.
- 캡처는 표시가 완료된 정적 상태다. 실제 게임 카메라·조명·URP·아틀라스, 입력/대사 진행/풀링/등장·퇴장 연출 및 전체 Play Mode/Player build는 검증 범위에 포함하지 않았다.

## 검증과 문서 영향

Unity 6000.4.2f1의 격리 프로젝트에서 검증용 C#를 컴파일하고 실제 TMP 글자와 NPC 위의 배경을 렌더했다. 불투명 말풍선 내부의 검사 영역은 두 배경에서 픽셀이 같고, 현재 반투명에서는 차이가 발생함을 확인했다. 준비 중 진단 코드의 공백 글리프 검사와 누락된 폰트 부모 머티리얼/TMP 리소스를 격리 프로젝트에서 보완했으며 게임 폰트는 변경하지 않았다.

생성한 파일은 비교 이미지 3장, 원본 렌더 6장, 검증용 소스·합성 도구·로그·설명·검사 결과와 ZIP이다. 기존 게임 자산·코드·Docs의 해시를 작업 전과 비교했다. 검증 증거를 보관한 뒤 경로를 확인해 격리 preview-project만 정리한다.
