술 / 화염 장판 - Aseprite 평면 탑다운 견본
2026-11-01

사용자 요청: 게임 시점에 맞게 입체감을 줄이고 Aseprite로 제작.
방법: Aseprite 1.3.18.6에서 Lua로 원본 픽셀과 레이어를 직접 작성.
이 버전은 이미지 생성 모델의 출력물을 축소한 것이 아님.

alcohol.aseprite: 64 x 64, 4프레임, 프레임당 160ms, 6색 + 투명.
fire.aseprite: 64 x 64, 4프레임, 프레임당 100ms, 5색 + 투명.
두 원본 모두 3개 레이어, Idle 태그, GroundCenter 피벗 (32,32).
각 sheet.png: 256 x 64, 왼쪽부터 1-4프레임, 여백 제거 없음.
각 frame-N.png: 투명 배경 64 x 64. GIF는 각 원본 재생 시간을 유지.
comparison-preview.gif: 두 효과의 원래 속도를 유지하는 3.2초 공통 루프, 4배 정수 확대.
비교 미리보기의 타일은 중립 배경이며 실제 Unity 게임 캡처가 아님.

시점 근거: Main Camera.prefab의 identity 회전 / 정사영, 기존 test-scene.png.
수정 방향: 눌린 타원 대신 거의 원형인 불규칙 바닥 면, 옆면/그림자/베벨 제거.
바닥 외곽과 색 면은 고정. 물결/기포, 열기/짧은 불꽃만 움직임.

검증: Aseprite에서 저장된 원본 재열기, 4프레임과 레이어/태그/피벗,
원본과 PNG의 픽셀 일치, 고정 바닥 레이어 검사(native-verification.txt).
PNG 색 수/알파/프레임 경계와 GIF 시간, 4배 픽셀 확대 확인.
실제 Unity 임포트/컴파일/게임 재생 검증은 수행하지 않음.
씬/프리팹/기존 게임 자산 변경 없음. 기존 AI 참고 시트 보존.

재현: Aseprite -b --script-param outputDir=<이 폴더> --script author-puddles.lua
검증: Aseprite -b --script-param outputDir=<이 폴더> --script verify-native.lua
