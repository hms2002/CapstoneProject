# 아이템 도감 — 실험적인 정보 배치 10안 (revision 9)

**후속 사용자 결정으로 후보에서 제외됨:** 왼쪽은 목록, 오른쪽은 선택한 아이템 정보로 고정한다. 아래 11–20안은 이 역할 경계를 바꾼 과거 탐색 자료이며 승인/적용 후보가 아니다.

## 작업 범위

작업 모드: Implementation — Aseprite 승인 견본 제작. 사용자는 기존 10안보다 더 실험적인 레이아웃을 요청했다. 이번에는 공통 팔레트와 책 외형을 유지하면서 목록 위치, 양쪽 페이지의 정보 분배와 읽는 방향을 바꿨다.

- 좌우 페이지는 원본 1920×1080 캔버스 기준 각각 460×576이며 X=464 / 996, Y=286이다. 중앙 72픽셀 접힘선은 보존했다.
- 무기 능력치와 유물 레벨은 별도 영역으로 유지했다.
- 기존 이름·스토리·스탯·기술·입력·쿨타임·유물 효과·레벨·상세 단축키를 생략하지 않았다. 문구는 새 너비에 맞춰 재배치·줄바꿈했다.
- 기존 글자색 역할, Galmuri9, 프로젝트의 아이템·스킬 이미지와 밝은 종이를 사용했다. 좁은 두 열의 기술명은 18px, 일반 기술명은 27px, 본문은 18px/23px 행간이다.
- Unity 적용은 포함하지 않는다.

11/12는 장비 기록과 기술을 한 페이지씩 맡기되 방향을 반전했다. 13/14는 목록을 양쪽 하단/상단으로 옮겼다. 15는 중앙 접힘선 양옆의 안쪽 여백에 목록을 나눴다. 16은 번호와 가로 구분선을 맞춰 기술 이름/입력과 설명을 두 페이지에서 대조한다. 17은 아이템 주위를 둘러 목록을 놓았다. 18은 장비와 목록을 대각선으로 분배했다. 19는 왼쪽 두 열에 기술을, 오른쪽에 장비와 마지막 기술을 놓았다. 20은 오른쪽 위 두 열과 아래 한 열을 결합했다.

16은 시선 이동이 늘고, 14/19/20은 열이 좁아 줄바꿈이 늘어난다. 13/14/15의 양면 목록은 선택 순서와 게임패드 탐색 규칙을 적용 단계에서 정해야 한다. 이들은 비교를 위한 디자인 선택지이며 해당 조작을 구현한 상태가 아니다.

## 정보와 제작

무기는 뇌창 갈라론의 이름, 전기 +5, 전체 스토리, 기본 스킬 두 분기와 낙뢰 표식, Mouse1/Mouse1/Q, 3s/3s/10s, 전체 간단 설명을 포함한다. 유물은 쇳덩이의 예비 탄창, Lv. 2/3, Q/E, 여섯 효과 문단과 남은 장전 횟수 문단을 포함한다. 분단·대조표 안에서도 원래 문장은 모두 남겼다.

목록 순서·획득 상태·페이지 수는 견본용 예시이며 실제 저장 데이터와 연동하지 않았다. 미획득 항목의 검은 실루엣과 상세 숨김은 추후 게임 적용에서 계속 유지할 조건이다.

글자 레이어는 프로젝트 Galmuri9를 단색 픽셀 방식으로 렌더링했다. 의미 강조 색과 얇은 불투명 외곽선을 유지했다. 도형·아이콘 합성 및 최종 PNG/aseprite 저장은 네이티브 Aseprite로 수행했다.

## 확인과 남은 사항

10개 무기·유물 비교판과 일부 개별 원본을 시각적으로 검토했다. 본문 배치에는 잘라내기나 말줄임을 사용하지 않았고, 새 레이어는 동일 크기의 두 페이지 경계 안에 배치했다. 임시 제작 스크립트는 삭제했으며 일회용 실행 도구를 저장소에 추가하지 않았다.

자동 테스트, Unity PlayMode 확인, 컴파일·임포트는 실행하지 않았다. Assets, 씬, 프리팹, ProjectSettings는 변경하지 않았다. 최종 디자인 선택, 실제 TMP 표현, 더 긴 상세/다국어 문구의 스크롤, 여러 페이지에 걸친 선택/포커스 동작은 적용 단계에 남는다.
