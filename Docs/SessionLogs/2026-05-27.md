Changed:
- Added `DemoCheatSettingsSO` as a Resources-loaded runtime configuration asset for build-usable demo cheat hotkeys.
- Added `DemoCheatHotkeyController`, bootstrapped before scene load, to listen for F9/F10/F11/F12 while demo cheats are enabled and no scene transition is active.
- Added `DemoCheatService` to apply max health, nearest portal prompt-anchor warp, owned weapon cooldown reset, and cumulative AttackAdd increases through existing runtime APIs.

Reason:
- Demo builds need fast, low-friction recovery/navigation/balance-test cheats without relying on Editor-only debug windows.
