# 2026-10-24 — 클로에 대화 초상화 교체

## 변경 사항

- Notion `클로에 대사` 페이지의 현재 표정표를 기준으로 그림자 보스(클로에)의 대화 초상화 13종을 교체했다.
- `Assets/_Project/Art/Sprites/Bosses/Shadow/DialogueSprite/`에는 아래 파일만 남겼다.
  - `Overwhelmed`, `Normal`, `disappointment`, `ShySmile`, `Flustered`, `Dizzy`, `Determined`, `HideFace`, `Thinking`, `Eager`, `Panic`, `Hiding`, `Surprise`
- 기존 `Boss1*` GUID 네 개는 각각 `Overwhelmed`, `disappointment`, `ShySmile`, `Flustered`에 재사용했다. `CapstoneLoadingRuntime` 주소 지정 항목도 새 파일 경로로 변경해 preload 참조가 끊기지 않도록 했다.
- `SpriteLibraryAsset_WitchBoss.spriteLib`의 `Face` 라벨을 위 13개로 재작성했다. `Normal`, `Panic`, `Surprise`의 기존 GUID는 유지했다.

## 검증

- 이미지 13장 모두 PNG 1254×1254px 정사각형임을 확인했다.
- PNG 13개와 `.meta` 13개의 파일 집합, GUID 중복 없음, SpriteLibrary `Face` 라벨 13개가 Notion 표와 일치함을 정적으로 확인했다.
- `Boss1*` 주소 지정 경로가 남아 있지 않고 새 네 preload 경로가 존재함을 확인했다.

## 남은 확인

- 이 환경의 Unity batch mode는 GUI 프로세스 대기 상태에 머물며 로그를 남기지 않아, Unity import·컴파일·Play Mode 검증은 실행하지 못했다.
- 다음 Unity Editor 실행 시 새 PNG와 `.spriteLib`가 import되는지, 대화 UI에서 11·12번 망토 표정의 체감 위치가 다른 표정과 자연스러운지 수동 확인이 필요하다.
- 기존 샘플 Ink에는 현재 SpriteLibrary에 원래부터 없던 `Smile`, `CloseEye`, `Angry` 라벨이 남아 있다. 이번 범위는 Notion의 13개 표정 등록이므로 Ink 별칭/치환은 수행하지 않았다.

  - 부정 반응: `disappointment` → `disappointment`
