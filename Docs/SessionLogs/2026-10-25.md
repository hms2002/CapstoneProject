# 2026-10-25 — 클로에 첫 조우 대사 교체

## 변경 사항

- `ShadowBossIntroDialogue_Animated`의 첫 조우를 탐색전 중심의 새 대사로 교체했다.
  - 첫 선택지는 간수장에게 출입 허가를 묻는 반응이며, 호감도 `+1`을 유지한다.
  - 다른 선택지는 비어 있는 감옥을 지킬 이유를 묻는 가벼운 반문이다.
  - 두 분기 모두 클로에가 간수장과 마왕의 명령에 따라 길을 막는다고 정리한 뒤 전투로 들어간다.
  - 전투 직전의 `발밑은 조심해 주세요` 경고는 요청대로 `Determined` 표정을 사용한다.
- 짧은 문장은 한 대화 카드 안에서 읽히도록 문장 단위 Ink 행을 합쳤다.
- 새 대사를 Ink 원문, 생성 JSON, `GameText.csv`, 활성 Ink 로컬라이즈 목록에 동기화했다.
- 런타임이 `loc:` 태그의 테이블 값을 우선하는 구조이므로, 다섯 언어의 `GameText` 테이블 자산도 같은 9개 키로 동기화했다.

## 검증

- Ink를 프로젝트의 `Ink-Libraries.dll`로 컴파일하고 생성 JSON을 `Ink.Runtime.Story`로 로드했다.
- Ink 원문·`InkInventory.json`·`GameText.csv`의 활성 키가 모두 9개이며 서로 일치함을 확인했다.
- 사용 표정 `Normal`, `Surprise`, `disappointment`, `Determined`가 클로에 SpriteLibrary에 모두 존재함을 확인했다.
- `# anim: normal`은 기존 대화에서 사용하는 유효한 애니메이션 태그임을 확인했다.
- Unity batch CSV import는 이 환경에서 편집기 프로세스가 로그 없이 즉시 종료되어 실행할 수 없었다. 대신 해당 다섯 StringTable의 대상 엔트리를 CSV 값으로 제한적으로 동기화했다.

## 남은 확인

- Unity Editor에서 첫 조우를 실제 재생해 대화 카드 분량과 `Determined` 전환 타이밍을 확인한다.
- 제거된 예전 한 줄의 StringTable 키는 더 이상 Ink/CSV/활성 목록에서 참조하지 않는다. Unity Localization의 다음 전체 CSV import 시에도 비참조 키를 정리할지 별도 결정할 수 있다.
