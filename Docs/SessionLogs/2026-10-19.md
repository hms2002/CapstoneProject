## 슬라임 여왕 멜타 시민권 발급식

- 모드: Implementation. 사용자 승인에 따라 `SlimeQueenIntroDialogue_MeltaNotion_Animated.ink`의 기본 진입 대사를 시민권 발급식 에피소드로 교체했다.
- 두 선택지는 각각 `MELTA_CITIZENSHIP_MOTTO_END`와 `MELTA_CITIZENSHIP_NUMBER_END`의 전용 결말을 거쳐 전투로 이어진다. 전자는 호감도 +1, 후자는 기존 선택 실패 태그를 사용한다.
- 멜타의 대사 `한 명의 초상화를 그렸는데 셋이 되어 있었다!`는 사용자 요청대로 서술형 과거 표현으로 반영했다. 슬라임 발화에는 별도 portrait를 쓰지 않아 기존 멜타 portrait dim 처리 흐름을 유지한다.

### 시민권 후속 대화와 선택 플래그

- `# set_boss_flag: <id>` Ink 태그와 NPC별 영구 `dialogueFlags` 저장 목록을 추가했다. `BossDialogueFlag` 조우 조건은 현재 보스 또는 지정 NPC의 플래그 기록 여부를 비교한다. 기존 세이브는 빈 목록으로 정규화되어 호환된다.
- 멜타의 시민권 발급식에서 `초상화 대신, 각자 고른 문장을 적자.` 선택 시 `melta.citizenship.motto_selected`를 기록한다.
- 새 `MELTA_CITIZENSHIP_IDENTITY_FOLLOWUP` knot는 선택 기록이 있고 아직 재생하지 않은 경우 우선순위 750으로 선택된다. 재생 시작 시 `melta.citizenship.identity_followup_seen`을 기록해 한 번만 등장한다. 시간 임박(1000), 저체력(900), 번개 창(800)은 이 후속 대화보다 우선한다.
- 최종 후속 대사는 사용자 확정본으로 반영했다. 긍정 선택지는 시민 수 증가를 왕국 확장으로 해석하는 멜타의 개그를, 부정 선택지는 슬라임을 반죽처럼 합치려 한 용사를 질책하는 흐름을 사용한다.
- 새 대사 19개와 두 선택지를 `GameText.csv`의 5개 언어 열에 추가하고 공식 importer로 String Table에 반영했다.

### 검증

- Unity batch compilation은 새 C# 저장/태그/조건 코드를 오류 없이 컴파일했고, `MeltaCitizenshipFollowupAuthoring`이 `SlimeQueenBossNpc`에 두 플래그 조건과 우선순위 750을 Unity `SerializedObject` API로 저작한 것을 로그와 자산 readback으로 확인했다.
- `FullInkLocalizationCompile.RunBatch`가 `SlimeQueenIntroDialogue_MeltaNotion_Animated.ink`를 포함한 활성 Ink JSON을 공식 컴파일했다. 생성 JSON에 `MELTA_CITIZENSHIP_IDENTITY_FOLLOWUP`, 두 플래그 태그, 두 선택지와 모든 새 `loc` 키가 포함됨을 확인했다.
- `LocalizationSheetSetup.ImportBatch`가 5개 언어 GameText table import를 성공했다.
- 후속 전체 `FullLocalizationValidation`은 기존 `GlobalUIRoot/CreatureTabLabel`의 locale preview material 설정 문제로 실패했다. 이번 대사·플래그 변경과 무관하며 수정하지 않았다. Play Mode 대화 재생/세이브 재시작 검증은 실행하지 않았다.

## 스피리 상태 조우 대사

- 모드: Implementation. 사용자 확정 대사에 따라 스피리의 재조우 상태 대사 9개를 추가했다. 조건은 마왕의 인내심 60초 이하, 체력 30% 이하, `Weapon.CrimsonBoundary` 보유, 이전 보스 승패, 가방 가득 참, 호감도 5 이상, 재조우와 기본이다.
- 첫 조우에는 모든 상태 규칙이 `HasMetBoss`를 요구하게 해 기존 맨정신 `DRAGON_01`을 유지한다. 이후에는 `DragonDialogueStartKnotSelector`가 기존 취한 상태 전투 진입 knot인 `DRAGON_01_COMMON`을 선택해 냉정한 첫 조우 연출을 반복하지 않는다.
- `SpiriEncounterDialogueAuthoring`이 `DragonBossNpc`의 Ink 참조와 9개 우선순위 규칙을 `SerializedObject` API로 저작한다. 수동 YAML 저작은 하지 않았다.
- 새 9개 `loc` 키와 5개 언어 초안을 `GameText.csv`/Ink inventory에 추가했다.

### 검증

- Unity 6000.4.2f1이 새 에디터 도구를 포함해 컴파일했고, `FullInkLocalizationCompile`이 `SpiriBossEncounter.ink`를 포함한 활성 Ink를 공식 컴파일했다. 생성 JSON, NPC asset readback, 5개 언어 String Table 키를 확인했다.
- `git diff --check`은 이번의 텍스트·C# 소스 파일에서 통과했다. 새 Editor C# 파일은 Unity 생성 `.csproj`에 아직 포함되지 않아 MSBuild가 이를 다루지 못했다. Unity 컴파일이 해당 파일의 검증 근거다.
- 전체 `FullLocalizationValidation`은 기존 `GlobalUIRoot/CreatureTabLabel`의 locale preview material 저작 문제로 실패했다. 새 스피리 키·Ink와 무관하며 수정하지 않았다. Play Mode에서 첫 조우/재조우/저장 재시작은 실행하지 않았다.
