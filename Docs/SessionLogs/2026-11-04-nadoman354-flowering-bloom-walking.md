# 개화 강화 기본 공격 중 이동

- [PlayerCombatInput2D](../../Assets/_Project/Runtime/Features/Player/Input/PlayerCombatInput2D.cs)의 기본 공격 이동 잠금에서 만개 참격을 제외했다. 실행 중인 공격의 데이터로 구분해 강화 지속 시간이 도중에 끝나도 해당 참격은 걸으면서 마칠 수 있다. 다음 일반 평타에는 기존 이동 제한이 적용된다.
- 일반 평타와 강화 평타가 서로 다른 데이터 타입을 사용하고 조준과 연타가 별도의 제어 조건을 참조하는 것을 소스에서 확인했다. Gameplay.csproj의 MSBuild 빌드는 경고와 함께 성공했다.
- 자동 테스트와 Unity 플레이 확인은 실행하지 않았다. 이동 키를 누른 채 강화 평타를 연타할 때의 방향 전환과 강화 종료 후 첫 일반 평타의 이동 제한은 사용자가 추후 확인한다.
