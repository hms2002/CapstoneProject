# 2026-10-26 — 클로에 첫 조우 로컬라이즈 import 확인

## 검증

- 열린 Unity Editor에서 `Tools > Localization > Import GameText CSV`를 실행했다.
- Console에 `[Localization] Imported GameText CSV with 5 explicit locale mappings.` 성공 로그가 남았고, 다섯 `GameText` 언어 테이블의 수정 시각이 갱신됐다.
- Console 오류 수는 0개였다.
- 표시된 경고 1개는 프로젝트가 레거시 Input Manager를 사용한다는 Unity 경고이며, 이번 클로에 대화·로컬라이즈 작업과 무관하다.
- 클로에 첫 조우 Ink·활성 Ink 목록·CSV의 `loc:` 키는 9개로 서로 일치함을 재확인했다.

## 남은 확인

- 실제 플레이에서 첫 조우를 열어 대사 카드 분량과 표정 전환을 확인하면 완전한 체감 검증이 된다.

## 후속 수정 — 호감도 연출 뒤 첫 대사 누락

- 실제 플레이에서 클로에의 긍정 선택지 뒤 `...허가를요? 아... 그런 건, 생각해 본 적 없었어요.`가 출력되지 않는 현상을 확인했다.
- 원인은 `add_aff` 태그가 연출을 기다리는 동안 해당 Ink 줄의 표시를 막고, 완료 콜백이 곧바로 다음 Ink 줄로 진행하던 공통 대화 처리였다.
- `DialogueController`가 blocking 태그 완료 뒤 방금 처리한 비어 있지 않은 대사를 먼저 표시하도록 수정했다. 따라서 표정 전환과 호감도 이펙트 뒤에도 해당 줄이 유지된다.
- 소스 diff의 공백 오류는 없음을 확인했다. Unity Editor 컴파일 및 해당 분기 실플레이 재확인은 남아 있다.
