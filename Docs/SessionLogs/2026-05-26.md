## Flowering Weapon Reveal Duplicate Playback

Changed:
- `FloweringBloomPresentationController.ApplyWeaponBloomSprite(true)` now returns early when the Bloom weapon sprite is already applied or a weapon reveal coroutine is still running.
- `FloweringBloomPresentationController.PlayWeaponReveal(...)` clears its coroutine handle on early exits so an empty/cancelled reveal attempt cannot block a later valid apply.
- `FloweringRuntimeState.BeginBloom(...)` now preserves the just-finished cut-in presentation while resetting runtime Bloom state for active Bloom setup.
- `Docs/ErrorLog.md` records the duplicate reveal trap.

Reason:
- `PlayCutIn(...)` starts the Bloom weapon reveal during the fade.
