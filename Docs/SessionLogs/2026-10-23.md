# 2026-10-23

## 마왕 재조우 본 대사 - 파괴된 회랑의 수리비

### 변경

- `DemonKingIntroDialogue_Animated.ink`에 `DEMONKING_REPAIR_COST` knot를 추가했다.
  - 파괴된 회랑의 보수 견적과 밀린 서류에 지친 마왕, 이를 장난스럽게 놀리는 `검?`의 만담이다.
  - `가능한 조심할게.`는 호감도 `+1`, `부순 만큼 더 멋지게 고치면 되겠네.`는 수치 변화 없이 실패 선택 연출을 사용한다.
- `DemonKingDialogueStartKnotSelector`의 재조우 후보와 마왕 보스 씬 직렬화 목록을 다음 두 knot로 갱신했다.
  - `DEMONKING_LESSON`
  - `DEMONKING_REPAIR_COST`
  - 첫 조우에는 선택기가 `null`을 반환하므로 기존 마왕 도입 Ink 루트가 유지된다. 재조우부터는 두 후보를 균등 무작위로 선택한다.
- 새 문장 14개를 Ink 인벤토리와 한국어·영어·일본어·중국어 간체·중국어 번체 문자열 테이블에 등록하고, Unity 로컬라이징 에셋을 갱신했다.

### 검증

- 프로젝트 CSV 파서 기준으로 모든 행이 6개 열인지 확인했다. 초기 실행에서 새 영어 문장 하나의 쉼표가 인용 처리되지 않은 것을 발견해 수정한 뒤 재검증했다.
- Unity 6000.4.2f1 batch mode에서 `DemonKingLessonDialogueAuthoring.ApplyBatch`를 실행해 Ink 컴파일, 마왕 씬 후보 목록 직렬화, 로컬라이징 import를 완료했다.
- 컴파일 JSON의 `DEMONKING_REPAIR_COST`, 씬의 두 후보 knot, Ink 인벤토리 14개 항목 및 5개 언어 문자열 14개를 정적으로 확인했다.

### 남은 확인

- Play Mode에서 첫 조우에는 기존 도입만 출력되는지, 재조우마다 교육 대사와 수리비 대사가 균등하게 선택되는지, 두 선택지의 호감도/실패 연출과 `검?` 대사 중 마왕 초상화 어둡게 처리를 수동 확인해야 한다.
