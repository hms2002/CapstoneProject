## PrewarmTrace 파일 잠금 및 반복 오류 복구

- 모드/범위: Implementation. 사용자가 앞선 평가의 해결 시도를 요청하고 Unity 종료를 확인한 뒤 진행했다. Editor 전용 추적 기록기의 파일 저장·오류 재시도만 수정했다. 기존 JSON 스키마, 테스터별 파일명, 저장/추천 읽기 경로, 20세션 보관 기준, runtime bridge, 씬·프리팹·대사·게임 저장 데이터는 유지했다.
- [PrewarmTraceRuntime.cs](../../Assets/_Project/Editor/Build/Loading/PrewarmTraceRuntime.cs): 실패해도 저장 시도 시간을 기록하고, 실패 상태에서는 자동 재시도를 5초 간격으로 제한한다(정상 간격 1초 유지). IOException/UnauthorizedAccessException은 실패 구간마다 경고 한 번으로 보고하고 dirty 데이터를 메모리에 유지하며, 성공하면 실패 상태를 해제한다. Play Mode 종료 시 마지막 저장 시도도 같은 오류 처리를 거친다. 기존 callback/ResetSession 이름은 유지해 trace isolation의 reflection 계약을 보존했다.
