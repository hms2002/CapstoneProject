# 05-1. 복합 오브젝트 방별 세부 배치

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

> 🆕 **2026-09-02 신규 문서** — 제물 보상 Alcove를 기준으로 복합 Prop의 방별 세부 배치 전체 과정을 설명합니다.

## 언제 사용하는가

하나의 완성된 프리팹 안에 여러 기능 오브젝트가 들어 있지만, 방마다 내부 배치만 다르게 만들고 싶을 때 사용합니다.

현재 대표 예시는 `SacrificeRewardAlcove`입니다.

- `제물 동상` (`OfferingStatue`)
- `보상 문` (`RewardDoor`)
- `보상 상자` (`TreasureChest`)

내부 참조, 제물 비용, 문 잠금과 상자 동작은 프리팹이 계속 소유합니다. 방 데이터는 공개된 자식의 자세 차이만 저장합니다.

## 전체 배치와 자식 배치의 차이

| 조정 위치 | 영향 범위 |
| --- | --- |
| 오브젝트 카드의 일반 Transform | 동상·문·상자를 포함한 복합 프리팹 전체 |
| `복합 오브젝트 세부 배치`의 슬롯 | 선택한 자식 하나, 현재 방의 해당 Placement만 |
| Prefab Mode에서 원본 수정 | 그 프리팹을 사용하는 모든 방의 기본값 |

방마다 다른 배치를 만들 목적이라면 Prefab Mode에서 자식을 옮기지 말고 Room Piece Editor의 세부 배치를 사용합니다.

## 작업 순서

1. `4. 오브젝트`에서 `SacrificeRewardAlcove`를 `Prop`으로 배치합니다.
2. 오브젝트 카드의 일반 Transform으로 Alcove 전체 위치·회전·크기를 먼저 맞춥니다.
3. 카드 아래 `복합 오브젝트 세부 배치`에서 수정할 자식을 찾습니다.
4. `이 방에서 자세 재정의`를 켭니다.
5. 저장할 값만 `위치 적용`, `회전 적용`, `크기 적용`으로 켭니다.
6. 숫자를 입력하거나 `Scene View에서 대상 선택`을 누르고 Scene View 핸들로 조정합니다.
7. `5. 검증·저장`에서 검증한 뒤 저장합니다.
8. 방을 다시 열어 값이 복원되는지 확인하고 Play Mode에서 상호작용과 Collider를 확인합니다.

## 채널을 필요한 것만 켜는 이유

위치만 방마다 다르게 하고 싶다면 `위치 적용`만 켭니다. 회전과 크기는 프리팹 기본값을 계속 따라가므로 나중에 공통 기본값을 고쳐도 해당 방에 반영됩니다.

`이 방에서 자세 재정의`를 끄면 저장된 재정의가 제거되고 작업 공간의 자식도 프리팹 기본 자세로 돌아갑니다.

Scene View에서 자식을 움직여도 꺼진 채널은 방 데이터로 캡처되지 않습니다.

## 검증 규칙

- Slot Id는 프리팹 안에서 비어 있거나 중복되면 안 됩니다.
- 방 데이터가 참조하는 Slot Id가 프리팹에 존재해야 합니다.
- 프리팹이 허용한 위치·회전·크기 채널만 재정의할 수 있습니다.
- Scale을 재정의할 때 어떤 축도 0이면 안 됩니다.
- 큰 자식의 전체 Sprite와 Collider가 벽, 문, 다른 자식을 침범하는지는 Scene View와 Play Mode에서 직접 확인합니다.

프리팹의 Slot Id를 변경하거나 삭제하면 이미 저장된 방의 재정의가 유효하지 않게 됩니다. 슬롯 계약을 바꿀 때는 기존 `RoomTemplateSO`도 함께 마이그레이션합니다.

## 새 복합 프리팹을 지원할 때

프로그래머 또는 테크니컬 디자이너가 프리팹에 `RoomCompositePoseAuthoring`을 추가하고 다음을 정의합니다.

- 안정적인 Slot Id
- 기획자에게 보일 이름
- 대상 자식 Transform
- 허용할 위치·회전·크기 채널

툴은 이 계약이 있는 프리팹만 자동으로 감지합니다. 특정 프리팹 이름을 Room Piece Editor나 `DungeonRoomBuilder`에 하드코딩하지 않습니다.

기존 제물 보상 프리팹에 표준 슬롯만 다시 설치해야 할 때는 `Tools > Dungeon > Update Sacrifice Reward Alcove Pose Slots`를 사용합니다. 이 메뉴는 존재하는 자식의 수동 Transform을 보존하고 누락된 슬롯 계약을 갱신합니다.
