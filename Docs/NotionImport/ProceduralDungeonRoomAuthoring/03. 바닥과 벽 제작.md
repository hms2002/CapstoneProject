# 03. 고정 타일 레이어 제작

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 사용하는 도구

Room Piece Editor는 별도 타일 브러시를 제공하지 않습니다. Unity의 Tile Palette와 Tilemap Brush를 그대로 사용합니다.

`2. 타일`의 각 버튼은 그릴 Tilemap을 선택하며 괄호 안에 예약 영역 내부 타일 수를 표시합니다.

## 레이어 계약

| 레이어 | 용도 | 캐릭터 통과·충돌 |
| --- | --- | --- |
| `UnderFloor` | 물, 하수, 용암, 낭떠러지 같은 바닥 아래 배경 | 통과 가능, 물리 판정 없음 |
| `Floor` | 기본 이동 바닥 | 통과 가능, Ground 물리 스캔 기준 |
| `FloorDetail` | 균열, 얼룩, 이끼, 카펫 같은 평면 장식 | Floor 위에 배치, 통과 가능 |
| `GroundDecoration` | 풀, 종이, 작은 잔해 같은 입체감 있는 장식 | Floor 위에 배치, 통과 가능 |
| `Wall` | 기본 벽과 방 경계 | 통과 불가, 유일한 Tilemap Collider |
| `WallDetail` | 벽기둥, 깃발, 부조, 배관 같은 벽 장식 | Wall 위에 배치, 아래 Wall 충돌 사용 |
| `Foreground` | 아치 상단, 기둥 윗부분, 천장 같은 전경 장식 | 통과 가능, 캐릭터 앞에 렌더링 |
| `OverlayFX` | 안개, 빛줄기, 먼지, 어둠, 반사광 | 통과 가능, 전경 오버레이로 렌더링 |

`GroundProp`은 Tilemap 레이어가 아닙니다. 큰 돌, 상자, 책상처럼 개별 충돌이나 동작이 필요한 오브젝트는 `4. 오브젝트`에서 `Prop`으로 배치합니다. 충돌 여부와 물리 레이어는 해당 프리팹에서 설정합니다.

## Floor 그리기

1. `2. 타일 > Floor` 버튼을 누릅니다.
2. Tile Palette에서 현재 테마의 Floor 타일을 선택합니다.
3. Scene View에서 플레이어가 실제로 걸을 셀을 모두 칠합니다.

Floor 타일이 실제 방 모양을 결정합니다.

- ㄴ자·ㄱ자 방의 비어 있는 안쪽에는 Floor를 칠하지 않습니다.
- 오브젝트 기준 셀에는 Floor가 필요합니다.
- 소켓으로 사용할 경계 두 셀에도 Floor가 필요합니다.

## Wall 그리기

1. `Wall` 버튼을 누릅니다.
2. 현재 테마의 Wall 타일을 선택합니다.
3. 방 외곽과 필요한 내부 장애물을 칠합니다.

## 출입구는 먼저 막아 둔다

> 모든 소켓 후보는 방 샘플에서 닫혀 있어야 합니다.

소켓이 차지하는 경계 두 셀에는 Floor와 Wall을 모두 칠합니다.

- Floor: 연결됐을 때 통과할 길
- Wall: 연결되지 않았을 때 출구를 막는 벽
- 맵 생성기: 실제 연결이 선택된 소켓의 Wall만 제거

샘플 제작 단계에서 출입구를 미리 뚫으면 연결되지 않은 소켓으로 방 밖에 나갈 수 있습니다.

## 타일 수와 영역 밖 경고

툴은 예약 영역 안의 여덟 레이어별 타일 개수를 표시합니다.

- 영역 안 타일: `RoomTemplateSO`에 저장됩니다.
- 영역 밖 타일: 경고가 표시되고 저장 데이터에서 제외됩니다.

영역 밖 타일이 의도된 것이라면 예약 크기를 수정합니다. 실수로 칠한 타일이면 Tilemap에서 지웁니다.

## 큰 방 제작 팁

- 먼저 예약 직사각형의 네 모서리를 확인합니다.
- 실제 이동 경로를 Floor로 만든 뒤 외곽 Wall을 두릅니다.
- 좁은 목 부분이 2칸 문과 몬스터 이동을 수용하는지 확인합니다.
- 큰 스프라이트 Wall은 셀 중심에 실제 Collider가 존재하는지도 Play Mode에서 확인합니다.

## 완료 조건

- [ ] 실제 이동 영역에 Floor가 끊기지 않았다.
- [ ] 방 외곽이 Wall로 닫혀 있다.
- [ ] FloorDetail과 GroundDecoration은 Floor 위에 있다.
- [ ] WallDetail은 Wall 위에 있다.
- [ ] 개별 충돌이 필요한 장식은 GroundDecoration이 아니라 Prop으로 배치했다.
- [ ] 소켓 후보 두 셀에 Floor와 Wall이 모두 있다.
- [ ] 예약 영역 밖 타일 경고를 확인했다.
