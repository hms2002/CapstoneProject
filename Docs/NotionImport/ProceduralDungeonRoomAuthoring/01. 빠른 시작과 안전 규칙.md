# 01. 빠른 시작과 안전 규칙

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 10분 빠른 시작

1. Unity 메뉴에서 `Tools > Dungeon > Room Piece Editor`를 엽니다.
2. 창 상단에서 `테마 룸 라이브러리`를 선택합니다.
3. 기존 방 카드에서 `복제`를 누릅니다.
4. `1. 기본`에서 Room Id를 새 이름으로 변경합니다.
5. `2. 타일`에서 Floor와 Wall을 확인하거나 수정합니다.
6. `3. 출입구`에서 2칸 소켓과 닫힌 Wall을 확인합니다.
7. `4. 오브젝트`에서 배치와 Kill Lock 연결을 확인합니다.
8. `6. 맵 미리보기`에서 `저장하지 않은 현재 편집 방 포함`을 켜고 생성합니다.
9. `5. 검증·저장`에서 전체 검증을 통과시킵니다.
10. 새 `RoomTemplateSO`로 저장하고 선택한 라이브러리에 등록합니다.

## 새 방을 처음부터 만들 때

`새 방 만들기`에 방 ID, 역할, 예약 크기, 난이도 단계, 등장 가중치를 입력하고 `전용 작업 공간에서 새 방 만들기`를 누릅니다.

그다음 순서는 다음과 같습니다.

`기본 → 타일 → 출입구 → 오브젝트 → 맵 미리보기 → 검증·저장`

오브젝트가 없는 방이라면 `4. 오브젝트`는 건너뛰어도 됩니다.

## 안전 작업 공간

방 제작 오브젝트는 저장되지 않는 additive 작업 공간에만 생성됩니다.

- 현재 게임 씬의 Hierarchy에 방 제작용 Grid나 프리팹을 추가하지 않습니다.
- 기존 씬을 자동 저장하거나 교체하지 않습니다.
- dirty 상태인 `Untitled` 씬이 열려 있으면 작업 공간 생성을 막습니다.
- 방을 바꾸거나 작업 공간을 닫을 때 저장하지 않은 변경이 있으면 확인합니다.
- 작업 공간 자체를 씬 에셋으로 저장하지 않습니다.

> 실제 저장 결과물은 씬이 아니라 `RoomTemplateSO`입니다.

## 미리보기 안전성

- 현재 편집 방은 메모리의 임시 방 데이터로만 사용됩니다.
- 원본 `RoomTemplateSO`와 선택한 `RoomThemeLibrarySO`는 미리보기로 변경되지 않습니다.
- 미리보기 생성과 삭제는 방 편집의 저장 필요 상태를 만들지 않습니다.
- Door, Monster, Chest, Portal, Prop과 인카운터 로직은 실행하지 않습니다.

## 작업을 중단할 때

- 저장할 변경이라면 먼저 `5. 검증·저장`을 사용합니다.
- 테스트용 배치만 지우려면 `6. 맵 미리보기 > 미리보기 지우기`를 누릅니다.
- 작업 공간을 닫을 때 경고가 나오면 저장 여부를 다시 판단합니다.
- Unity 스크립트 컴파일 후 미리보기 표식이 사라지면 미리보기를 다시 생성합니다.
