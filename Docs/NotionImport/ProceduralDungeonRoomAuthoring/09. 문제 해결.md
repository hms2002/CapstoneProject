# 09. 문제 해결

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 작업 공간이 열리지 않는다

### dirty 상태의 Untitled 씬 경고

저장되지 않은 `Untitled` 씬이 열려 있으면 툴이 작업 공간 생성을 막습니다. 필요한 내용을 씬으로 저장하거나 변경을 버린 뒤 다시 시도합니다.

### 이미 작업 공간이 열려 있다

기존 Room Authoring Workspace로 전환하거나, 저장 여부를 판단한 뒤 작업 공간을 닫고 다시 엽니다.

## 타일이 저장되지 않는다

- 예약 영역 밖 타일인지 확인합니다.
- Floor 또는 Wall이 아닌 다른 Tilemap에 그렸는지 확인합니다.
- 툴의 `바닥 레이어 선택`, `벽 레이어 선택`으로 대상 Tilemap을 다시 선택합니다.
- 예약 크기를 수정했다면 전체 검증을 다시 실행합니다.

## 소켓 검증에 실패한다

| 메시지 성격 | 확인할 것 |
| --- | --- |
| 경계가 아님 | 두 셀이 예약 영역의 같은 바깥 경계에 붙어 있는지 확인합니다. |
| 방향 불일치 | Direction이 방 바깥쪽을 향하는지 확인합니다. |
| 폭 불일치 | 현재 소켓 폭은 2칸으로 고정합니다. |
| 셀 겹침 | 다른 소켓과 공유하는 셀이 없는지 확인합니다. |
| Floor/Wall 없음 | 소켓의 두 셀 모두에 Floor와 Wall을 칠합니다. |
| 중복 ID | 각 Socket Id를 고유하게 바꿉니다. |

좌표를 직접 고치기보다 잘못된 소켓을 지우고 Scene View 경계 클릭으로 다시 배치하는 편이 빠릅니다.

## 연결되지 않은 출구로 밖에 나갈 수 있다

방 샘플에서 소켓 Wall을 미리 지운 경우입니다. 모든 소켓의 두 셀을 Wall로 닫아 두세요. 생성기가 실제 연결에 사용한 소켓만 뚫습니다.

## 오브젝트 검증에 실패한다

- Monster 프리팹에 자식 포함 `Enemy`가 있는지 확인합니다.
- Chest 프리팹에 자식 포함 `TreasureChest`가 있는지 확인합니다.
- Portal 프리팹에 자식 포함 `ScenePortal`이 있는지 확인합니다.
- Placement Id가 비어 있거나 중복되지 않는지 확인합니다.
- 오브젝트 기준 셀이 예약 영역 안의 Floor 위인지 확인합니다.

## Kill Lock이 작동하거나 연출되지 않는다

- 대상 상자 프리팹에 `ChestMonsterKillLock`이 구성돼 있는지 확인합니다.
- Monster의 `Kill Lock Chest`가 올바른 Placement Id를 가리키는지 확인합니다.
- 상자 카드의 Linked Monsters 수가 의도와 같은지 확인합니다.
- 일반 상자를 사용했다면 툴이 Kill Lock 구성이나 연출을 자동 추가하지 않습니다.
- 맵 미리보기에서는 게임플레이 프리팹과 연출을 실행하지 않으므로 Play Mode에서 확인합니다.

## 미리보기에 현재 방이 안 나온다

1. `저장하지 않은 현재 편집 방 포함`을 켭니다.
2. 현재 방의 역할이 생성 대상과 맞는지 확인합니다.
3. 등장 가중치가 `0`보다 큰지 확인합니다.
4. Start 또는 Boss 역할이라면 해당 생성 설정이 필요한지 확인합니다.
5. 다른 후보와의 가중치 선택이므로 Seed를 바꾸어 여러 번 생성합니다.

## 목표 방 수보다 적게 생성된다

배치기가 더 붙일 수 있는 유효 연결을 찾지 못한 상태입니다.

- 방 간격 또는 최소 복도 길이가 현재 소켓 배치에 비해 너무 큰지 확인합니다.
- 후보 방의 소켓 방향이 다양하게 준비됐는지 확인합니다.
- 큰 예약 영역끼리 충돌하는지 확인합니다.
- 한 소켓 방이 중간 확장 후보로 자주 선택되는지 확인합니다.
- 방 수를 낮춰 성공 여부를 비교하고 Seed를 바꿉니다.

## 미리보기와 Play Mode가 다르다

미리보기는 레이아웃과 타일 중심의 Visual Only 빌드입니다. Door, Monster, Chest, Portal, Prop, 인카운터와 상호작용은 실행하지 않습니다.

레이아웃이 같아도 다음 항목은 Play Mode에서만 검증할 수 있습니다.

- Collider와 실제 이동
- 문 개폐와 입장 잠금
- 몬스터 추적과 방 소속 판정
- Kill Lock 상자 연출
- 포털 상호작용과 씬 이동
- 조명, 카메라와 테마별 런타임 기믹

## 저장 버튼을 눌렀는데 취소된다

- 전체 검증 오류를 먼저 해결합니다.
- 새 방 저장 경로에 같은 이름의 에셋이 이미 있는지 확인합니다.
- 원본 갱신 시 `갱신할 원본`이 비어 있지 않은지 확인합니다.
- 라이브러리 자동 등록을 원한다면 창 상단에 라이브러리가 선택돼 있어야 합니다.

## 컴파일 뒤 미리보기가 사라졌다

미리보기는 저장 대상이 아닌 임시 시각화입니다. 스크립트 리로드 후 `6. 맵 미리보기 > 미리보기 생성`을 다시 누릅니다.
