# 07. 동적 맵 미리보기

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 무엇을 검증하는가

맵 미리보기는 실제 `DungeonLayoutAssembler`를 사용합니다. 같은 라이브러리, 방 데이터, Seed와 생성 설정이면 런타임과 같은 방 선택 및 연결 결과를 계산합니다.

확인 가능한 것:

- 방 선택과 배치 위치
- 예약 영역 충돌
- 연결된 소켓
- 복도 길이와 방향
- 실제 Floor/Wall 타일 결과
- 방별 Monster, Chest, Portal, Prop 위치

미리보기에서는 Door 프리팹, Monster 실제 스폰, Kill Lock과 인카운터, Chest/Portal/Prop 상호작용을 실행하지 않습니다.

## 생성 순서

1. 상단의 테마 룸 라이브러리를 확인합니다.
2. `6. 맵 미리보기`를 엽니다.
3. 현재 편집 내용을 시험하려면 `저장하지 않은 현재 편집 방 포함`을 켭니다.
4. Seed, 방 개수, 보스 방 포함 여부를 설정합니다.
5. 필요하면 복도 Floor/Wall 타일을 지정합니다.
6. `동적 생성 미리보기`를 누릅니다.

## 설정 의미

| 설정 | 의미 |
| --- | --- |
| 현재 편집 방 포함 | 원본 편집은 저장본을 현재 복사본으로 임시 대체하고, 새 방은 임시 후보로 추가합니다. |
| Seed | 같은 결과를 재현하는 정수입니다. |
| 보스 방 포함 | 마지막 방을 Boss 후보에서 선택합니다. |
| 방 개수 | Start와 선택적 Boss를 포함한 목표 개수입니다. |
| 복도 타일 오버라이드 | 지정하지 않으면 라이브러리에서 가장 많이 사용된 Floor/Wall을 자동 선택합니다. |
| 방당 최대 배치 시도 | 겹치지 않는 다음 방을 찾는 최대 시도 횟수입니다. |
| 최소 복도 길이 | 모든 연결의 기본 최소 길이입니다. |
| 방 크기 반영 비율 | 연결 방의 크기가 복도 길이에 미치는 정도입니다. |
| 복도 길이 난수 폭 | Seed 기반 추가 길이의 최대 범위입니다. |

## Scene View 표식

| 표식 | 의미 |
| --- | --- |
| 초록 방 테두리 | 현재 편집 중인 임시 방이 선택되었습니다. |
| 역할별 색 테두리 | 각 방의 예약 영역입니다. |
| 청록 점선과 점 | 연결된 두 소켓입니다. |
| `M` / `C` / `P` / `O` | Monster / Chest / Portal / Prop |

## 현재 방 0회

현재 방 포함은 강제 배치가 아니라 정상 후보 등록입니다.

1. `랜덤 시드`로 다른 결과를 확인합니다.
2. 현재 Room 역할이 생성 과정에서 필요한지 확인합니다.
3. 등장 가중치가 양수인지 확인합니다.
4. 소켓과 예약 크기가 유효한지 확인합니다.

미리보기만을 위해 가중치를 과장하면 런타임과 다른 선택 규칙이 되므로 권장하지 않습니다.

## 부분 생성

- `No open room socket remains`: 중간 방의 남는 소켓이 부족합니다.
- `Failed to place room ... without overlap`: Seed, 시도 수, 복도 길이, 방 크기와 소켓을 확인합니다.
- `no usable Start room`: Start 방의 가중치, 크기와 소켓을 확인합니다.
- `no usable Boss room`: Boss 방을 추가하거나 보스 방 포함을 끕니다.

## Seed 검증 방법

- 대표 Seed 하나를 기록해 회귀 확인에 사용합니다.
- `랜덤 시드`로 최소 5회 이상 생성합니다.
- 실패 Seed는 실패 이유와 함께 기록합니다.
- 라이브러리 순서나 가중치를 바꾸면 같은 Seed 결과도 달라질 수 있습니다.
