# 04. 출입구 소켓

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 소켓이란

다른 방과 연결될 수 있는 방 경계의 2칸 출입구 후보입니다. 실제 생성에서는 서로 반대 방향이고 폭이 같은 소켓만 연결됩니다.

현재 폭은 문과 복도에 맞춰 항상 `2 cells`입니다.

## 가장 쉬운 배치 방법

1. `3. 출입구`를 엽니다.
2. `Scene View에서 경계를 클릭해 소켓 배치`를 켭니다.
3. 방의 원하는 경계에 마우스를 올립니다.
4. 초록 미리보기의 두 셀과 바깥 방향을 확인하고 클릭합니다.
5. `Esc`로 배치 모드를 종료합니다.

툴이 가장 가까운 경계, 바깥 방향, 2칸 시작 위치와 기존 소켓 겹침을 자동 처리합니다.

## 빠른 중앙 배치

`위`, `오른쪽`, `아래`, `왼쪽` 버튼은 선택한 경계 중앙 근처의 비어 있는 2칸에 소켓을 만듭니다.

## 소켓 카드의 값

| 입력 | 의미 |
| --- | --- |
| Socket Id | 같은 방 안에서 소켓을 구분하는 고유 이름입니다. |
| Direction | 방 바깥쪽 방향입니다. |
| Width | 현재 고정값 `2 cells`입니다. |
| Local Cell | 2칸 소켓의 기준 시작 셀입니다. |

Up/Down은 Local Cell에서 오른쪽으로 2칸, Left/Right는 위쪽으로 2칸을 사용합니다. 좌표 직접 입력보다 클릭 배치를 권장합니다.

## 위치 수정

1. 소켓 카드에서 `Scene View에서 선택`을 누릅니다.
2. Scene View 이동 핸들로 위치를 조정합니다.
3. 자동 검증 메시지를 확인합니다.

## 필수 조건

- 방 경계 안의 연속된 두 셀이어야 합니다.
- Direction은 방 바깥쪽을 향해야 합니다.
- 다른 소켓과 셀이 겹치면 안 됩니다.
- 두 셀 모두 Floor와 Wall을 가져야 합니다.
- 한 방에 최소 하나의 유효한 소켓이 필요합니다.

## 소켓 수를 정하는 기준

- 일반 확장 방: 다음 방을 붙일 여유를 위해 보통 2개 이상을 권장합니다.
- Start: 경로 설계에 따라 1개 이상
- Boss: 마지막 종단형이라면 1개 가능
- 한 소켓 Combat/Treasure: 선택된 순간 이후 경로가 끝날 수 있으므로 주의

## 자주 하는 실수

- 소켓 위치의 Wall을 미리 지운다.
- Right 소켓인데 Direction을 Left로 설정한다.
- 한 셀만 Floor/Wall을 칠한다.
- 두 소켓의 셀이 겹친다.
- 큰 빈 공간 쪽 경계에 실제로 도달할 수 없는 소켓을 둔다.
