## 용어

> 🆕 **2026-09-02 업데이트** — 복합 Pose 슬롯, 저장 데이터와 런타임 적용 책임을 추가했습니다.

| 용어 | 의미 |
| --- | --- |
| 방 템플릿 | 한 방의 레이아웃과 구현 정보를 저장한 `RoomTemplateSO`입니다. |
| 테마 라이브러리 | 같은 보스·복도 테마에서 사용할 방 후보 모음인 `RoomThemeLibrarySO`입니다. |
| 예약 영역 | 방 전체를 감싸며 다른 방과 복도의 침범을 막는 직사각형입니다. |
| 소켓 | 다른 방과 연결될 수 있는 경계의 2칸 출입구 후보입니다. |
| Placement | Monster의 공통 역할/스테이지 고정 지점 또는 Chest, Portal, Prop의 프리팹·위치·연결 데이터입니다. |
| 복합 Pose 슬롯 | 복합 프리팹이 방별 재정의를 허용한 자식 Transform의 안정적인 ID·대상·허용 채널 계약입니다. |
| Travel Slot | Interaction, Trigger, ArrivalOnly 이동 매개체의 방 안 위치와 방식을 저장하며 목적 씬은 저장하지 않습니다. |
| Runtime Anchor | 자체 완결형 Prop 프리팹 내부에서 NPC·순간이동 모듈이 위치를 찾는 `ProceduralRoomAnchor`입니다. 독립 방 배치 데이터가 아닙니다. |
| Kill Lock | 지정한 몬스터를 모두 처치할 때까지 보상 상자를 잠그는 구성입니다. |
| Seed | 같은 후보와 설정에서 배치 결과를 재현하기 위한 난수 시작값입니다. |
| Visual Only | 게임플레이 프리팹을 실행하지 않고 레이아웃과 타일만 만드는 미리보기 빌드입니다. |
| 복도 장식 프로필 | 테마별 Landmark 최대 수와 모듈 목록을 저장하는 `CorridorDecorationProfileSO`입니다. |
| 복도 장식 모듈 | 가로(+X) 또는 세로(+Y) 전용 2칸 폭으로 만든 짧은 8레이어·GroundProp 조각인 `CorridorDecorationModuleSO`입니다. |

## 데이터 흐름

`Room Piece Editor → RoomTemplateSO → RoomThemeLibrarySO → DungeonLayoutAssembler → DungeonRoomBuilder → DungeonGenerator`

이동은 `Room Travel Slot → Procedural Travel Binding Editor → Scene-local DungeonRoomBuilder Binding → SceneConnectionSO` 흐름으로 별도 연결합니다.

복도 장식은 `DungeonGenerationProfileSO → CorridorDecorationProfileSO → CorridorDecorationComposer → DungeonRoomBuilder` 흐름으로 적용됩니다.

- `Room Piece Editor`: 제작 복사본을 만들고 검증·저장·미리보기를 제공합니다.
- `RoomTemplateSO`: 예약 크기, 소켓, 타일, 오브젝트 루트 배치와 선택적인 자식 Pose 재정의를 저장합니다.
- `RoomCompositePoseAuthoring`: 복합 프리팹이 조정 가능한 자식 슬롯과 허용 채널을 공개합니다.
- `RoomThemeLibrarySO`: 테마별 방 후보를 제공합니다.
- `DungeonLayoutAssembler`: 테마와 무관하게 후보 방의 배치와 연결을 결정합니다.
- `DungeonRoomBuilder`: 결정된 결과에 타일, 복도, 문과 오브젝트를 구현합니다.
- `DungeonGenerator`: 씬에서 생성 순서와 런타임 설정을 조율합니다.

## 레이아웃 데이터와 구현 데이터

한 방 템플릿 안에 저장되지만 용도는 나뉩니다.

### 레이아웃 조립에 필요한 정보

- Room Id와 역할
- 예약 크기
- 등장 가중치
- 소켓 위치, 방향과 폭

### 방 구현에 필요한 정보

- Floor와 Wall 타일
- Warrior/Mage/Tank 역할별 Monster 지점과 StageMonsterSet 또는 스테이지 고정 Enemy 프리팹
- Chest, Portal, Prop 프리팹과 Transform
- 복합 Prop Placement의 슬롯별 위치·회전·크기 재정의
- Monster에서 Kill Lock Chest로 향하는 연결
- Interaction, Trigger, ArrivalOnly Travel Slot
- 자체 완결형 Prop 프리팹 내부의 런타임 앵커와 기능 구성

배치기는 테마별 규칙을 하드코딩하지 않고, 선택된 라이브러리가 제공하는 방 데이터를 조합합니다.
