# 06. 검증과 저장

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 전체 검증

`5. 검증·저장 > 지금 전체 검증`을 누릅니다. 창 아래쪽의 자동 검증 요약도 현재 상태를 주기적으로 갱신합니다.

## 검증 항목

### 기본 정보

- Room Id가 비어 있지 않고 선택한 라이브러리 안에서 고유하다.
- Grid와 여덟 고정 Tilemap 슬롯 참조가 모두 있다.
- 예약 크기가 유효하고 영역 안에 타일이 있다.
- FloorDetail·GroundDecoration은 Floor 위에 있고 WallDetail은 Wall 위에 있다.

### 소켓

- 소켓이 최소 한 개 있다.
- Socket Id가 비어 있거나 중복되지 않는다.
- Direction과 경계 위치가 맞고 폭이 2칸이다.
- 다른 소켓과 겹치지 않는다.
- 각 소켓 셀에 Floor와 Wall이 모두 있다.

### 오브젝트

- Placement Id가 고유하다.
- 공통 역할 Monster는 Warrior/Mage/Tank StageMonsterSet이 있고, 스테이지 Monster는 자식 포함 Enemy가 있는 고정 프리팹이다. 다른 Kind도 필요한 컴포넌트를 가진 프리팹이어야 한다.
- 기준 셀이 예약 영역 안이며 Floor 위다.
- Monster의 Kill Lock Chest ID가 실제 상자를 가리킨다.
- 대상 상자 프리팹에 `ChestMonsterKillLock`이 있다.

### 이동 슬롯

- Travel Slot Id가 비어 있거나 같은 방 안에서 중복되지 않는다.
- 기준 셀이 예약 영역 안이며 Floor 위다.
- 별도 도착점을 사용하면 도착 셀도 예약 영역 안이며 Floor 위다.
- 저장 후 이동 연결·연출 편집기에서 씬별 Builder, Connection A/B Side와 연출을 연결해야 실제 이동이 활성화된다.

## 새 방으로 저장

1. `저장 후 선택한 테마 라이브러리에 자동 등록` 여부를 정합니다.
2. `검증 후 새 RoomTemplateSO로 저장`을 누릅니다.
3. Unity 저장 창에서 폴더와 에셋 이름을 확인합니다.
4. 저장 완료 메시지와 라이브러리 등록 결과를 확인합니다.

기존 에셋 경로를 선택하면 덮어쓰지 않고 저장을 취소합니다.

## 불러온 원본 갱신

1. `갱신할 원본` 필드가 의도한 `RoomTemplateSO`인지 확인합니다.
2. `검증 후 원본 템플릿 갱신`을 누릅니다.
3. 확인 창의 에셋 경로를 다시 읽습니다.
4. Apply 후 저장 완료 메시지를 확인합니다.

원본을 보존해야 한다면 `복제해서 새 방 만들기` 또는 새 템플릿 저장을 사용합니다.

## 자동 라이브러리 등록

- 켜짐: 저장 성공 후 선택한 라이브러리에 중복 없이 등록합니다.
- 꺼짐: 방 에셋만 저장합니다.
- 선택한 라이브러리가 없으면 자동 등록할 수 없습니다.

저장 전에 창 상단의 테마 ID를 다시 확인하세요.

## 저장 후

1. 라이브러리 방 목록에서 새 방이 보이는지 확인합니다.
2. 같은 방을 다시 열어 타일, 소켓, 오브젝트가 복원되는지 확인합니다.
3. 여러 Seed로 맵 미리보기를 생성합니다.
4. 전용 절차 복도 씬에서 Play Mode 검증을 수행합니다.
