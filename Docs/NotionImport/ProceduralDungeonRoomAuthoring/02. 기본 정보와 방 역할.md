# 02. 기본 정보와 방 역할

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 새 방 입력값

| 입력 | 작성 기준 |
| --- | --- |
| 방 ID | 선택한 라이브러리 안에서 고유하게 작성합니다. 예: `Dragon_Combat_Wide_02`. |
| 방 역할 | Start, 일반 확장, Boss 중 실제 용도에 맞게 선택합니다. |
| 예약 크기 | 가장 바깥쪽 타일까지 포함하는 가로·세로 셀 수입니다. |
| 난이도 단계 | 향후 난이도 정책용 메타데이터입니다. 현재 배치기는 이 값으로 방을 걸러내지 않습니다. |
| 등장 가중치 | 같은 역할 후보 중 선택될 상대 확률입니다. `0`이면 배치 후보가 되지 않습니다. |

## 방 역할

| 역할 | 현재 생성기에서의 의미 |
| --- | --- |
| `Start` | 첫 방 후보입니다. 라이브러리에 사용 가능한 Start 방이 최소 한 개 필요합니다. |
| `Combat` | 일반 전투 확장 방입니다. |
| `Treasure` | 보상용 확장 방입니다. |
| `Shop` | 상점용 확장 방입니다. |
| `Event` | 이벤트용 확장 방입니다. |
| `Boss` | `보스 방 포함` 설정에서 마지막 방 후보가 됩니다. |
| `Exit` | 현재 v0의 일반 확장 후보에는 포함되지 않습니다. |

## 예약 크기와 실제 모양

예약 크기는 다른 방과 복도가 침범하지 못하는 직사각형입니다. 실제 방 모양은 Floor 타일이 결정합니다.

- 직사각형 방: 보이는 외곽 크기와 예약 크기가 대부분 같습니다.
- ㄴ자·ㄱ자 방: 가장 튀어나온 지점을 모두 감싸는 직사각형을 예약합니다.
- 빈 안쪽 모서리: Floor가 없어도 예약 영역에는 포함됩니다.

예약 크기를 실제 타일보다 작게 만들면 저장 시 영역 밖 타일이 제외될 수 있습니다. 너무 크게 만들면 생성 가능한 공간을 불필요하게 차지합니다.

## 기존 방 수정

- 라이브러리 방 카드의 `편집`
- Project 창에서 `RoomTemplateSO` 선택 후 `기존 방 직접 선택 > 원본 편집`

불러온 것은 작업 공간의 편집 복사본입니다. `검증 후 원본 템플릿 갱신` 전에는 원본이 바뀌지 않습니다.

## 기존 방 복제

- 라이브러리 방 카드에서 `복제`를 누르거나 `복제해서 새 방 만들기`를 사용합니다.
- Room Id 뒤에 `_Copy`가 붙습니다.
- 원본 연결이 제거되므로 새 에셋으로 저장됩니다.
- 저장 전에 의도를 드러내는 고유 ID로 변경합니다.

## 권장 이름 예시

`테마_역할_형태_번호` 형식을 권장합니다.

- `Shadow_Combat_LargeL_01`
- `Dragon_Treasure_Sacrifice_01`
- `Slime_Boss_Terminal_01`
