# 07-1. 복도 장식 제작과 미리보기

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 방 미리보기와 무엇이 다른가

Room Piece Editor의 `동적 맵 미리보기`는 방 그래프와 전체 연결을 검증합니다. `Tools > Dungeon > Corridor Decoration Editor`는 그중 복도 한 줄을 골라, 입력한 길이에 어떤 장식 조각이 조합되는지 검증합니다.

- 방 위치와 복도 길이는 기존 레이아웃 생성기가 결정합니다.
- 복도 장식은 결정된 길이를 바꾸지 않습니다.
- 장식 데이터가 없거나 일부 셀을 채우지 못해도 기본 Floor/Wall 복도는 유지됩니다.
- 두 미리보기는 같은 비저장 작업 공간을 사용하며 원본 게임플레이 씬을 수정하지 않습니다.

## 데이터 구성

`DungeonGenerationProfileSO → CorridorDecorationProfileSO → CorridorDecorationModuleSO`

| 데이터 | 책임 |
| --- | --- |
| 생성 프로필 | 테마 장식 프로필 하나를 참조 |
| 장식 프로필 | Landmark 최대 수와 모듈 목록 |
| 장식 모듈 | 전용 축(Horizontal/Vertical), 역할, 진행축 길이, 여덟 타일 레이어, GroundProp Pivot 배치 |

## 모듈 제작 순서

1. `Tools > Dungeon > Corridor Decoration Editor`를 엽니다.
2. 테마 생성 프로필과 복도 장식 프로필을 선택합니다.
3. 새 프로필이라면 `생성 프로필에 연결`을 누릅니다.
4. 모듈 ID, `복도 축`, 역할과 길이를 입력하고 `새 복도 조각 만들기`를 누릅니다.
5. 레이어 버튼과 Unity Tile Palette로 타일을 그립니다.
6. 필요하면 완성된 프리팹을 `GroundProp`으로 추가하고 Transform Pivot을 옮깁니다.
7. 검증 뒤 `새 모듈 저장 및 프로필 등록`을 누릅니다.

기존 모듈은 프로필 목록의 `편집` 또는 `모듈 직접 선택`으로 불러온 뒤 `현재 모듈 갱신 및 프로필 등록`으로 저장합니다.

## 좌표와 레이어 규칙

가로와 세로 조각을 별도로 만듭니다. 런타임은 Right/Left 연결에 `Horizontal`, Up/Down 연결에 `Vertical` 모듈만 선택합니다. 가로 조각을 90도 돌려 세로에 사용하지 않습니다.

| 축 | 기준 방향 | 진행축 | Floor | Wall | 전체 허용 범위 |
| --- | --- | --- | --- | --- | --- |
| Horizontal | `+X` | `x=0..Length-1` | `y=0,1` | `y=-1,2` | `x=0..Length-1`, `y=-1..2` |
| Vertical | `+Y` | `y=0..Length-1` | `x=0,1` | `x=-1,2` | `x=-1..2`, `y=0..Length-1` |

- 오른쪽과 위쪽 연결은 원본 그대로, 왼쪽과 아래쪽 연결은 같은 축 안에서 반전됩니다.
- 모든 타일과 GroundProp Pivot은 선택한 축의 전체 허용 범위 안에 둡니다.
- 레이어: `UnderFloor`, `Floor`, `FloorDetail`, `GroundDecoration`, `Wall`, `WallDetail`, `Foreground`, `OverlayFX`
- 오브젝트: 현재 `GroundProp`만 지원하며 충돌과 기능은 프리팹이 소유

Floor/Wall이 있는 셀은 기본 복도 타일을 교체하고, 나머지 레이어는 위에 합성됩니다.

## 역할 선택 규칙

| 역할 | 의미 |
| --- | --- |
| `Start` | 첫 문에 맞닿은 복도 첫 칸부터 사용하는 선택적 시작 조각 |
| `Middle` | 일반 본문 조각 |
| `Landmark` | 본문 후보 중 선택되는 강조 조각 |
| `Filler` | 남은 길이를 채우는 짧은 조각 |
| `End` | 반대편 문에 맞닿은 복도 마지막 칸까지 사용하는 선택적 종료 조각 |
| `Short` | 전체 복도 길이와 정확히 같을 때 우선하는 단일 조각 |

Landmark 제한은 최대값이지 보장값이 아닙니다. 남은 길이와 무작위 선택에 따라 0개일 수 있습니다. 임의 길이를 빠짐없이 꾸미려면 1칸 Filler를 등록합니다.

## 완성본 미리보기

| 입력 | 의미 |
| --- | --- |
| 전체 복도 길이 | 장식 모듈이 처음부터 끝까지 사용할 1~512칸 |
| 복도 축 | 가로는 `Horizontal`, 세로는 `Vertical` |
| 미리보기 Seed | 런타임 Seed 재현값 |
| 연결 번호 | 연결마다 다른 조합을 만드는 인덱스 |

`완성본 생성/갱신`을 누르면 선택 축의 복도, 문 A/B, 모듈 ID와 셀 범위가 Scene View에 나타납니다. 같은 축·길이·Seed·연결 번호는 같은 순서를 재현하며 Start와 End는 문 인접 셀까지 사용할 수 있습니다.

## 기본 예제

`Assets/_Project/Data/Dungeon/CorridorDecorations/{Shadow|Dragon|Slime}/`에 테마별 프로필 한 개와 열두 모듈이 있습니다.

- Horizontal: `Start_02`, `Middle_03`, `Landmark_04`, `Filler_01`, `End_02`, `Short_02`
- Vertical: `Vertical_Start_02`, `Vertical_Middle_03`, `Vertical_Landmark_04`, `Vertical_Filler_01`, `Vertical_End_02`, `Vertical_Short_02`

| 메뉴 | 용도 |
| --- | --- |
| `Tools > Dungeon > Examples > Install Theme Corridor Decoration Examples` | 예제 설치·갱신 및 생성 프로필 연결 |
| `Install Missing Vertical Corridor Decoration Examples` | 기존 모듈을 덮어쓰지 않고 누락 세로 예제 추가 |
| `Validate Theme Corridor Decoration Examples` | 프로필 3개·모듈 36개 검증 |
| `Validate Completed Corridor Previews` | 세 테마 가로·세로 길이 기반 조립 검증 |

예제 설치기는 같은 경로를 갱신합니다. 수동 변형을 보존하려면 별도 이름의 모듈로 복제한 뒤 실행합니다.
