# 작업 레시피: 새 전투 방

[← 시작 페이지](<../00. 절차적 던전 방 제작 툴.md>)

## 권장 제작 순서

1. 같은 테마의 비슷한 `Combat` 방을 찾아 `복제`합니다.
2. Room Id를 `테마_Combat_형태_번호` 형식의 고유한 값으로 바꿉니다.
3. 역할을 `Combat`으로 두고 예약 크기를 실제 외곽에 맞춥니다.
4. Floor로 전투 이동 영역을 만들고 Wall로 외곽을 완전히 닫습니다.
5. 경계마다 2칸 소켓을 배치합니다. 소켓 위치의 Wall은 지우지 않습니다.
6. Monster 프리팹을 Floor 위에 배치하고 고유한 Placement Id를 줍니다.
7. Kill Lock 상자가 필요하면 `ChestMonsterKillLock`이 구성된 Chest를 배치합니다.
8. 각 Monster의 `Kill Lock Chest`에서 그 상자를 선택합니다.
9. 출입구에서 전투 공간까지 충분한 진입 거리를 확보합니다.
10. `저장하지 않은 현재 편집 방 포함`을 켜고 여러 Seed로 맵 미리보기를 생성합니다.
11. 전체 검증을 통과시킨 뒤 새 `RoomTemplateSO`로 저장합니다.
12. 같은 테마 라이브러리에 등록됐는지 확인합니다.
13. 전용 절차 복도 씬의 Play Mode에서 입장 잠금과 처치 후 해제를 확인합니다.

## 배치 팁

- 문 바로 안쪽은 플레이어와 몬스터가 서로 막히지 않도록 비워 둡니다.
- 몬스터를 문 밖이나 예약 영역 경계 가까이에 두지 않습니다.
- 원거리 몬스터와 근거리 몬스터의 시작 위치가 한곳에 겹치지 않게 합니다.
- 큰 상자나 장식물이 유효한 출입구를 가리지 않게 합니다.
- 여러 상자가 있다면 Monster마다 의도한 Kill Lock 대상을 다시 확인합니다.

## 미리보기에서 볼 것

- 이 방이 실제 후보로 선택되는가
- 소켓 방향과 복도가 자연스럽게 이어지는가
- 예약 영역이 다른 방이나 복도와 겹치지 않는가
- 사용하지 않은 소켓이 막힌 상태로 표시되는가

> 가중치 선택이므로 현재 방을 포함해도 매 Seed마다 반드시 선택되지는 않습니다.

## Play Mode에서 볼 것

- 플레이어가 문을 통과해 방 안쪽에 진입한 뒤 문이 닫히는가
- 방 소속 몬스터가 빠짐없이 인카운터에 포함되는가
- 몬스터가 문 바깥에 고립되지 않는가
- 마지막 연결 몬스터 처치 후 Kill Lock 상자와 출입문이 정상 해제되는가

## 완료 체크

- [ ] Room Id가 고유하다.
- [ ] 모든 소켓 두 셀에 Floor와 Wall이 있다.
- [ ] Monster 기준 셀이 Floor 위다.
- [ ] Kill Lock 연결 대상이 올바르다.
- [ ] 여러 Seed의 미리보기를 확인했다.
- [ ] Play Mode 전투 흐름을 끝까지 확인했다.
