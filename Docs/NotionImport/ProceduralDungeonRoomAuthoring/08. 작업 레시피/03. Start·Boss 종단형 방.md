# 작업 레시피: Start·Boss 종단형 방

[← 시작 페이지](<../00. 절차적 던전 방 제작 툴.md>)

## Start 방

Start는 맵의 첫 방 후보입니다.

1. 역할을 `Start`로 설정합니다.
2. 플레이어가 생성될 안전한 Floor 공간을 충분히 둡니다.
3. 최소 한 개의 유효한 2칸 소켓을 둡니다.
4. 시작 직후 문이나 큰 오브젝트가 이동을 막지 않는지 확인합니다.
5. 선택한 테마 라이브러리에 사용 가능한 Start 방이 최소 한 개 있는지 확인합니다.

Start 방을 여러 개 만들면 가중치에 따라 첫 방이 달라질 수 있습니다.

## Boss 종단형 방

Boss 방은 `보스 방 포함` 설정에서 마지막 방 후보로 사용됩니다.

1. 역할을 `Boss`로 설정합니다.
2. 진입용 소켓 하나만 두는 종단형 구성을 사용할 수 있습니다.
3. 소켓 두 셀은 다른 방과 마찬가지로 Floor와 Wall로 닫아 둡니다.
4. 입장 후 전투 공간까지 충분한 진입 거리를 둡니다.
5. 보스, 보상, 포털처럼 강하게 결합된 요소는 검증된 프리팹 구성을 사용합니다.
6. 맵 미리보기에서 `보스 방 포함`을 켜고 마지막 연결을 확인합니다.
7. Play Mode에서 전투 시작부터 포털 상호작용까지 전 과정을 확인합니다.

## 한 소켓 방의 의미

한 소켓 방은 들어온 연결 외에 다음 확장 경로가 없습니다. 따라서 일반 확장 중간에 선택되면 해당 가지가 끝날 수 있습니다.

- Start: 시작점에서 바깥으로 나가는 한 소켓 구성이 가능합니다.
- Boss: 마지막 종단 방으로 적합합니다.
- Combat/Treasure: 의도적으로 가지를 끝낼 때만 사용합니다.

## 보스 방 포함 미리보기

- 일반 방 목표 수와 별도로 마지막 Boss 배치가 가능한지 확인합니다.
- 실패하면 Boss 후보의 소켓 방향, 예약 크기, 최소 복도 길이를 점검합니다.
- 다른 Seed에서는 성공하는지 비교해 특정 배치 조합 문제인지 확인합니다.

## 완료 체크

- [ ] 테마 라이브러리에 유효한 Start 후보가 있다.
- [ ] Start 생성 지점 주변이 안전하다.
- [ ] Boss의 진입 소켓과 진행 방향이 자연스럽다.
- [ ] Boss 포함 미리보기가 여러 Seed에서 완성된다.
- [ ] Boss 처치 후 보상과 포털 상호작용을 확인했다.
