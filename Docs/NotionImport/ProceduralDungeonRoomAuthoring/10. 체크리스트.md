# 10. 체크리스트

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 저장 전

### 기본

- [ ] 올바른 테마 라이브러리를 선택했다.
- [ ] Room Id가 라이브러리 안에서 고유하다.
- [ ] 역할과 등장 가중치가 의도와 맞다.
- [ ] 예약 크기가 모든 타일을 감싼다.
- [ ] 영역 밖 타일 경고를 확인했다.

### 타일과 소켓

- [ ] 이동할 모든 셀에 Floor가 있다.
- [ ] 방 외곽이 Wall로 닫혀 있다.
- [ ] FloorDetail과 GroundDecoration은 Floor 위에 있다.
- [ ] WallDetail은 Wall 위에 있다.
- [ ] 개별 충돌이 필요한 바닥 오브젝트는 Prop 프리팹으로 배치했다.
- [ ] 모든 소켓은 경계의 연속된 2칸이다.
- [ ] 모든 소켓의 방향이 바깥쪽을 향한다.
- [ ] 소켓끼리 셀이 겹치지 않는다.
- [ ] 모든 소켓 두 셀에 Floor와 Wall이 모두 있다.

### 오브젝트

- [ ] 모든 Placement Id가 고유하다.
- [ ] 공통 역할 Monster는 Warrior/Mage/Tank StageMonsterSet, 스테이지 Monster는 유효한 Enemy 프리팹이 있고 다른 Kind도 필수 컴포넌트가 일치한다.
- [ ] 모든 오브젝트 기준 셀이 Floor 위다.
- [ ] 큰 프리팹이 벽과 출입구를 막지 않는다.
- [ ] Monster와 Kill Lock Chest 연결이 의도와 맞다.
- [ ] Warrior/Mage/Tank 역할별 수와 위치가 의도와 맞다.
- [ ] 스테이지 고정 몬스터 프리팹과 위치가 의도와 맞다.
- [ ] 복합 Prop의 내부 참조가 프리팹에 구성돼 있다.
- [ ] 함정·레버·퍼즐은 자체 완결형 Prop으로 구성했다.
- [ ] Prop 내부 Anchor Slot Id가 사용 범위에서 고유하다.
- [ ] 런 중 보존이 필요한 Prop 내부 상태에 별도 캡처·복원 계약이 있다.

### 이동 Endpoint

- [ ] 모든 Travel Slot Id가 방 안에서 고유하다.
- [ ] 슬롯 방식이 `Interaction`, `Trigger`, `ArrivalOnly` 의도와 맞다.
- [ ] 이동 연결·연출 편집기에서 올바른 Builder와 방·슬롯을 선택했다.
- [ ] `SceneConnectionSO`, A/B Side와 현재 씬 이름이 일치한다.
- [ ] 현재 Side의 출발 방향 사용 여부와 실제 이동 방향의 전환 연출 프로필을 확인했다.
- [ ] `ArrivalOnly`의 역방향 Connection이 비활성이다.
- [ ] 바인딩 적용 후 대상 게임플레이 씬을 직접 저장했다.

### 미리보기와 저장

- [ ] 저장하지 않은 현재 방을 포함해 미리보기를 생성했다.
- [ ] 여러 Seed에서 목표 방 수와 연결 결과를 확인했다.
- [ ] 사용하지 않은 소켓이 막혀 있다.
- [ ] Boss 방이라면 Boss 포함 생성을 확인했다.
- [ ] `지금 전체 검증`을 통과했다.
- [ ] 새 저장과 원본 갱신 중 올바른 동작을 선택했다.
- [ ] 저장 대상 경로와 테마 라이브러리를 다시 확인했다.

## 저장 직후

- [ ] 라이브러리 방 목록에 새 방이 보인다.
- [ ] 저장한 방을 다시 열었을 때 여덟 고정 레이어 타일이 복원된다.
- [ ] 소켓 위치, 방향과 ID가 복원된다.
- [ ] 오브젝트 Transform과 연결 정보가 복원된다.
- [ ] 저장 후 미리보기도 정상 생성된다.

## Play Mode 최종 확인

- [ ] 플레이어가 Start 위치에서 정상 생성된다.
- [ ] 모든 연결 복도를 실제로 통과할 수 있다.
- [ ] 문이 소켓 끝에 있고 통행을 방해하지 않는다.
- [ ] 방 안쪽 진입 후 전투 문이 닫힌다.
- [ ] 보스 처치 수 0·1·2에서 각 역할 지점의 실제 몬스터가 단계별 미리보기와 일치한다.
- [ ] 스테이지 고정 지점은 보스 처치 수와 관계없이 지정한 몬스터를 생성한다.
- [ ] 몬스터가 문 바깥에 고립되지 않는다.
- [ ] 전투 완료 후 문과 Kill Lock 보상이 해제된다.
- [ ] 상자, 제물, 레버 등 상호작용 연출이 작동한다.
- [ ] 포털이 의도한 씬으로 이동한다.
- [ ] 카메라, 조명과 테마 기믹이 방 전체에서 정상이다.

> 미리보기 통과는 Play Mode 최종 확인을 대체하지 않습니다.
