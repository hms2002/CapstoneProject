# 10. 체크리스트

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 저장 전

### 기본

- [ ] 올바른 테마 라이브러리를 선택했다.
- [ ] Room Id가 라이브러리 안에서 고유하다.
- [ ] 역할과 등장 가중치가 의도와 맞다.
- [ ] 예약 크기가 모든 타일을 감싼다.
- [ ] 영역 밖 타일 경고를 확인했다.

### 타일과 소켓

- [ ] 이동할 모든 셀에 Floor가 있다.
- [ ] 방 외곽이 Wall로 닫혀 있다.
- [ ] 모든 소켓은 경계의 연속된 2칸이다.
- [ ] 모든 소켓의 방향이 바깥쪽을 향한다.
- [ ] 소켓끼리 셀이 겹치지 않는다.
- [ ] 모든 소켓 두 셀에 Floor와 Wall이 모두 있다.

### 오브젝트

- [ ] 모든 Placement Id가 고유하다.
- [ ] Kind와 프리팹의 필수 컴포넌트가 일치한다.
- [ ] 모든 오브젝트 기준 셀이 Floor 위다.
- [ ] 큰 프리팹이 벽과 출입구를 막지 않는다.
- [ ] Monster와 Kill Lock Chest 연결이 의도와 맞다.
- [ ] 복합 Prop의 내부 참조가 프리팹에 구성돼 있다.

### 미리보기와 저장

- [ ] 저장하지 않은 현재 방을 포함해 미리보기를 생성했다.
- [ ] 여러 Seed에서 목표 방 수와 연결 결과를 확인했다.
- [ ] 사용하지 않은 소켓이 막혀 있다.
- [ ] Boss 방이라면 Boss 포함 생성을 확인했다.
- [ ] `지금 전체 검증`을 통과했다.
- [ ] 새 저장과 원본 갱신 중 올바른 동작을 선택했다.
- [ ] 저장 대상 경로와 테마 라이브러리를 다시 확인했다.

## 저장 직후

- [ ] 라이브러리 방 목록에 새 방이 보인다.
- [ ] 저장한 방을 다시 열었을 때 타일이 복원된다.
- [ ] 소켓 위치, 방향과 ID가 복원된다.
- [ ] 오브젝트 Transform과 연결 정보가 복원된다.
- [ ] 저장 후 미리보기도 정상 생성된다.

## Play Mode 최종 확인

- [ ] 플레이어가 Start 위치에서 정상 생성된다.
- [ ] 모든 연결 복도를 실제로 통과할 수 있다.
- [ ] 문이 소켓 끝에 있고 통행을 방해하지 않는다.
- [ ] 방 안쪽 진입 후 전투 문이 닫힌다.
- [ ] 몬스터가 문 바깥에 고립되지 않는다.
- [ ] 전투 완료 후 문과 Kill Lock 보상이 해제된다.
- [ ] 상자, 제물, 레버 등 상호작용 연출이 작동한다.
- [ ] 포털이 의도한 씬으로 이동한다.
- [ ] 카메라, 조명과 테마 기믹이 방 전체에서 정상이다.

> 미리보기 통과는 Play Mode 최종 확인을 대체하지 않습니다.
