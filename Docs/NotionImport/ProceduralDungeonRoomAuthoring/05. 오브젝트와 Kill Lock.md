# 05. 오브젝트와 Kill Lock

[← 시작 페이지](<./00. 절차적 던전 방 제작 툴.md>)

## 오브젝트 배치 순서

1. `4. 오브젝트`를 엽니다.
2. `종류`를 선택합니다.
3. `추천 프리팹`에서 고르거나 `배치할 프리팹`에 직접 지정합니다.
4. `방 중앙에 배치 후 Scene View에서 이동`을 누릅니다.
5. Scene View에서 위치, 회전과 크기를 조절합니다.
6. Placement Id가 방 안에서 고유한지 확인합니다.

추천 프리팹은 선택한 테마 라이브러리의 기존 방에서 같은 종류만 모아 보여줍니다.

## 종류별 조건

| 종류 | 필수 구성 | 런타임 생성 방식 |
| --- | --- | --- |
| `Monster` | 자식 포함 `Enemy` | 기존 `MonsterSpawner` 경로 |
| `Chest` | 자식 포함 `TreasureChest` | 완성된 프리팹 인스턴스 |
| `Portal` | 자식 포함 `ScenePortal` | 완성된 프리팹 인스턴스 |
| `Prop` | 별도 공통 필수 컴포넌트 없음 | 완성된 프리팹 인스턴스 |

## 배치 데이터

Transform을 움직이면 Grid 기준 Local Cell, 셀 중심 Offset, 로컬 회전 각도와 Scale로 저장됩니다.

오브젝트 기준 셀은 예약 영역 안이며 Floor 위여야 합니다. 큰 프리팹의 전체 스프라이트나 Collider가 벽 밖으로 나가는지는 자동으로 확인하지 않습니다.

## Placement Id

Placement Id는 한 방 안에서 고유해야 합니다.

- `Monster_01`
- `Monster_02`
- `KillLockChest_01`
- `ExitPortal_01`

Monster가 상자를 참조할 때도 이 ID를 사용하므로, 상자 ID를 변경했다면 연결을 다시 확인합니다.

## Kill Lock 상자 연결

1. `ChestMonsterKillLock`이 이미 구성된 상자 프리팹을 Chest로 배치합니다.
2. 상자의 Placement Id를 설정합니다.
3. 각 Monster 카드의 `Kill Lock Chest`에서 해당 상자를 선택합니다.
4. 상자 카드의 `Linked Monsters` 수를 확인합니다.

> Kill Lock 동작과 연출은 상자 프리팹이 소유합니다. 툴이 일반 상자에 컴포넌트나 연출을 임의로 추가하지 않습니다.

## 복합 Prop

제물 석상, 내부 잠금 문, 보상 상자처럼 서로 강하게 연결된 구성은 완성된 복합 프리팹 하나를 Prop으로 배치할 수 있습니다.

- 내부 참조와 상호작용 규칙은 프리팹이 소유합니다.
- 방 데이터는 프리팹과 위치만 저장합니다.
- 저장 후 Play Mode에서 실제 상호작용을 확인합니다.

## 완료 조건

- [ ] 모든 Placement Id가 고유하다.
- [ ] Kind와 프리팹 구성이 일치한다.
- [ ] 모든 기준 셀이 Floor 위에 있다.
- [ ] 큰 프리팹이 벽과 출입구를 막지 않는다.
- [ ] Monster와 Kill Lock Chest 연결 수가 의도와 맞다.
