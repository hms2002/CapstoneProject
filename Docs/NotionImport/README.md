# Notion Import 문서

이 폴더에는 저장소 문서를 Notion 페이지 계층으로 가져오기 위한 복사본을 보관합니다.

## 절차적 던전 방 제작 툴

- 원본 폴더: `ProceduralDungeonRoomAuthoring/`
- 배포 파일: `ProceduralDungeonRoomAuthoring_NotionImport.zip`
- 시작 페이지: `00. 절차적 던전 방 제작 툴.md`

ZIP을 Notion 가져오기에 사용합니다. 폴더 계층이 유지되지 않는 환경에서는 압축을 해제한 뒤 번호 순서대로 시작 페이지 아래에 배치합니다.

각 시작 페이지의 `🆕 이번 업데이트` 요약과 본문의 `🆕 날짜 업데이트` 인용 블록은 직전 배포본에서 추가하거나 크게 바뀐 내용을 표시합니다. 다음 기능 업데이트 때는 날짜와 표시 대상을 함께 갱신합니다.

이 폴더의 문서는 Notion 가독성을 위한 파생본입니다. 코드 변경 후 기준 문서인 `Docs/Guides/ContentAuthoring/ProceduralDungeonRoomAuthoringGuide.md`와 함께 갱신합니다.

## 절차적 복도 시스템 전체 문서

- 원본 폴더: `ProceduralCorridorSystem/`
- 배포 파일: `ProceduralCorridorSystem_NotionImport.zip`
- 시작 페이지: `00. 절차적 복도 시스템.md`
- 기준일: 2026-09-02

이 묶음은 방 제작과 복합 Prop의 방별 자식 Pose 재정의뿐 아니라 세 일반 보스 테마 복도, 가변 길이 복도 장식 모듈과 완성본 미리보기, HUB·보스 연결, 방 진입·진행도 기반 몬스터 생성, 현재 봉인된 Slime NPC·복도 간 토관 정책, 런 중 상태 보존과 출시 전 체크리스트를 포함합니다. 현재 시스템을 새 Notion 루트 페이지로 가져올 때는 이 ZIP을 사용합니다.
