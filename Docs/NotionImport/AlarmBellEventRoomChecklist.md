# 경보 종 이벤트 방 제작 체크리스트

## 목적

경보 종 이벤트 방은 플레이어가 종을 울리면 방이 봉쇄되고, 엘리트 몬스터 웨이브를 처치한 뒤 문이 열리는 이벤트 방이다.

## 수정 위치

- `AlarmBellEncounterDefinition`
  - 웨이브 수
  - 몬스터 구성
  - HP 배율
  - 완료 경험치

- `AlarmBellEventModule.prefab`
  - 종 오브젝트
  - 스폰 포인트
  - VFX/SFX
  - 팝업 문구

- 방 템플릿
  - 이벤트 모듈 배치
  - 소켓 방향
  - `requireDeadEnd`
  - 방 크기/충돌 영역

- `RunMapEventGenerationProfile`
  - 테스트용 필수 등장 설정
  - 랜덤 이벤트 후보 등록

## 주의 사항

- 같은 웨이브 안에서는 스폰 포인트가 최대한 겹치지 않도록 처리된다.
- 스폰 포인트 수보다 몬스터 수가 많으면 주변 산포 위치를 사용한다.
- 현재 기본 데이터는 1웨이브 구성이다.
- 추가 몬스터가 더 나오게 하려면 `AlarmBellEncounterDefinition`의 웨이브 데이터를 늘려야 한다.
- 경보 종 방은 막다른 이벤트 방으로 쓰는 것을 기본으로 한다.
- 모든 몬스터 처치 후 문이 먼저 열리고, 완료 경험치/레벨업 보상 처리는 그 뒤에 진행된다.

## 테스트 체크

- 경보 종 상호작용 UI가 뜨는가?
- 종을 울리면 문이 닫히는가?
- 몬스터가 겹치지 않고 스폰되는가?
- 설정한 웨이브 수만큼 몬스터가 등장하는가?
- 모든 몬스터 처치 후 문이 열리는가?
- 완료 팝업이 출력되는가?
- 한 런에서 다시 사용할 수 없게 막히는가?
