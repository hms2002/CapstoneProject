# 07. 복도 간 단방향 이동

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 확정된 연결

```text
Shadow ──→ Slime
Dragon ──→ Slime
```

다음 연결은 없습니다.

- Slime→Shadow
- Slime→Dragon
- Shadow↔Dragon

## 출발 방

Shadow와 Dragon은 각각 필수 Event 방 하나를 가집니다.

- 토관과 상호작용 키로 출발합니다.
- 전투 방이 아니라 이동 역할만 담당합니다.
- Start에서 너무 가까운 곳을 피하도록 최소 그래프 거리 3을 요구합니다.

## 도착 방

Slime은 출발지별로 서로 다른 도착 방을 가집니다.

- `Slime_Event_ArrivalFromShadow`
- `Slime_Event_ArrivalFromDragon`

두 방의 토관은 `ArrivalOnly`입니다. 상호작용 프롬프트와 자동 Trigger가 없으므로 역방향 이동을 요청할 수 없습니다.

## 이중 단방향 방어

단방향은 두 위치에서 동시에 보장합니다.

1. `SceneConnectionSO`의 A→B만 활성화하고 B→A는 비활성화합니다.
2. Slime 도착 방을 `ArrivalOnly`로 저장합니다.

둘 중 하나만 사용하면 이후 프리팹이나 바인딩 변경으로 의도하지 않은 귀환 경로가 생길 수 있습니다.

## 토관 프리팹과 연출

- 기존 DrainPipe의 Sprite와 Collider 형태를 재사용합니다.
- 보스 기믹용 피해·공격 컴포넌트는 복사하지 않습니다.
- 출발 시 흡입·회전 후 Alpha 전환을 사용합니다.
- 도착 시 위치 이동과 Slime 물 도착 VFX를 사용합니다.
