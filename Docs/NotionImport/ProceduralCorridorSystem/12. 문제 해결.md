# 12. 문제 해결

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 맵 생성에 실패하거나 방 수가 부족하다

- Room Template의 점유 직사각형과 소켓 위치가 실제 타일보다 작지 않은지 확인합니다.
- 2칸 소켓이 방 경계에 있고 방향·폭이 올바른지 확인합니다.
- 필수 방의 거리·막다른 길·CycleDetour 조건이 방 수에 비해 지나치게 강하지 않은지 확인합니다.
- Generation Profile의 시도 횟수와 복도 길이 범위를 확인합니다.
- 미리보기의 실패 사유를 먼저 해결하고 씬 설치기를 다시 실행합니다.

## 사용하지 않은 소켓으로 밖에 나갈 수 있다

Room Template은 모든 소켓 자리를 처음부터 벽으로 막아 두어야 합니다. 조립기가 연결에 성공한 소켓만 2칸 폭으로 엽니다. 샘플 방에 미리 문구멍을 만들지 마세요.

## 돌아왔더니 맵이 바뀌었다

- 씬의 재방문 정책이 `PreserveDuringRun`인지 확인합니다.
- 이동이 `SceneConnectionTravelService`를 거치는지 확인합니다.
- 새 런 시작이나 런 종료가 의도치 않게 호출되지 않았는지 확인합니다.
- 에디터에서 씬을 직접 로드하는 테스트는 정상 이동 경로와 결과가 다를 수 있습니다.

## 몬스터나 상자가 다시 생긴다

오브젝트에 안정적인 런 상태 ID가 있는지, 현재 보존 대상 컴포넌트인지 확인합니다. 임의의 커스텀 NPC·퍼즐 상태는 자동 보존되지 않으므로 별도 상태 계약이 필요할 수 있습니다.

## 봉인한 토관 방이나 Slime NPC 방이 생성된다

해당 방 에셋을 삭제할 필요는 없습니다. 각 테마의 Room Theme Library와 `DungeonGenerationProfileSO.guaranteedRoomTemplates`에서 빠져 있는지 확인하고 `Tools > Dungeon > Remove Deprecated Corridor Pipe Travel`과 `Slime NPC Room > Seal Installed Content`를 실행합니다.

## 다른 방의 몬스터가 먼저 플레이어를 인식한다

- 공통 역할 Monster 지점에는 Warrior/Mage/Tank와 해당 `StageMonsterSetSO`, 스테이지 고정 지점에는 유효한 Enemy 프리팹이 연결되어 있는지 확인합니다.
- Monster 배치가 실제 프리팹이 아니라 `MonsterSpawnContainer` 스폰 지점으로 생성되는지 확인합니다.
- 전투 방의 안쪽 Entry Trigger를 통과하기 전에 몬스터가 Hierarchy에 나타난다면 피드백 마이그레이션을 다시 적용합니다.

## 문이 열리는 것처럼 보이지만 통과할 수 없다

- 전투가 남아 있다면 문 상호작용 자체가 차단되는 것이 정상입니다.
- 전투 종료 후에는 `DoorObject`가 열림과 동시에 장애물 Collider를 비활성화합니다. 계속 막힌다면 문 프리팹에 별도의 충돌 Collider가 중복되어 있지 않은지 확인합니다.

## 제물 보상 방의 자식 배치가 저장되지 않는다

> 🆕 **2026-09-02 업데이트** — 복합 Pose 재정의와 복도 GroundProp 편집 범위 관련 문제 해결 항목입니다.

- Room Piece Editor의 해당 슬롯에서 `이 방에서 자세 재정의`를 켰는지 확인합니다.
- 위치·회전·크기 중 실제로 저장할 채널을 켰는지 확인합니다. Scene View 조작은 활성 채널만 캡처합니다.
- 프리팹에 `RoomCompositePoseAuthoring`과 해당 Slot Id가 남아 있는지 확인합니다.
- 재정의를 끄면 프리팹 기본 자세로 돌아가는 것이 정상입니다.

## 복도 장식 GroundProp에서 자식별 세부 배치가 보이지 않는다

현재 복합 자식 Pose 편집은 Room Template의 Prop에만 제공됩니다. Corridor Decoration Editor는 모듈 안 GroundProp의 전체 Transform만 저장합니다. 내부 구성이 다른 복도 장식은 변형별 완성 프리팹을 사용합니다.

## 씬 이동이나 사망 후 BGM이 바뀌지 않는다

- `RunRouteBgmService`가 씬 로드 직후 다음 프레임에 경로 상태를 다시 읽는지 확인합니다.
- HUB 복귀 시 활성 또는 최근 Route Catalog에서 HUB BGM을 찾을 수 있어야 합니다.
- Game Over 연출이 `SoundManager`를 직접 바꾼 뒤에도 내부 BGM 캐시를 씬 경계에서 초기화하는지 확인합니다.

## HUB 이동은 되지만 진행 기록이 잘못된다

Endpoint 문자열만 보지 말고 Route Catalog, 현재 Stage 문맥, 보스 처치 키가 같은 테마를 가리키는지 확인합니다. HUB 복귀는 활성 런을 새로 시작하거나 초기화해서는 안 됩니다.

## 설치기를 다시 실행했더니 참조가 비었다

프로필과 Room Theme Library를 먼저 저장한 뒤 설치기를 실행하고, 콘솔 오류 없이 씬과 에셋이 저장되었는지 확인합니다. 설치기는 반복 실행 가능해야 하지만 수동 배치값을 덮어쓰는 필드가 있는지는 변경 전 확인합니다.

## 복도 장식이 나오지 않는다

- 해당 테마 `DungeonGenerationProfileSO`에 `CorridorDecorationProfileSO`가 연결되어 있는지 확인합니다.
- 장식 프로필의 등록 모듈 목록이 비어 있지 않은지 확인합니다.
- 가로만 꾸며진다면 `Vertical` 모듈이 등록되어 있는지 확인합니다. 가로 모듈은 세로 연결에 자동 회전되지 않습니다.
- 모듈 검증을 통과한 뒤 저장·등록 버튼을 눌렀는지 확인합니다.
- 장식하지 않은 셀도 기본 복도 Floor/Wall은 유지되므로, 기본 복도만 보인다면 프로필 연결부터 확인합니다.

## Landmark가 항상 나오지 않는다

정상 동작입니다. `복도당 Landmark 제한`은 최대값이며 최소 보장 수가 아닙니다. Landmark는 남은 길이에 맞아야 하고 Middle/Filler와 함께 무작위 후보로 선택되므로 0개일 수 있습니다.

## 완성 복도 중간이 기본 타일로 남는다

남은 길이에 들어갈 등록 모듈이 없으면 조립기는 모듈을 늘이거나 자르지 않고 해당 셀을 건너뜁니다. 임의 길이를 모두 꾸미려면 1칸 `Filler` 모듈을 등록합니다.

## 완성본 미리보기가 생성되지 않는다

- 장식 프로필과 유효한 등록 모듈이 있는지 확인합니다.
- Horizontal은 `x=0..Length-1`, `y=-1..2`, Vertical은 `x=-1..2`, `y=0..Length-1` 안에 모든 타일과 GroundProp Pivot이 있는지 확인합니다.
- 스크립트 컴파일 뒤 창을 다시 열고 `완성본 생성/갱신`을 누릅니다.
- 이 미리보기는 전체 맵 미리보기와 동시에 유지되지 않습니다. 다른 미리보기를 생성하면 이전 임시 루트가 정리됩니다.
