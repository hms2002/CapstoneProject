# 02. 기획자 빠른 시작

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 방을 만들거나 수정할 때

1. Unity 메뉴에서 `Tools > Dungeon > Room Piece Editor`를 엽니다.
2. Shadow, Dragon, Slime 중 작업할 테마 라이브러리를 선택합니다.
3. 새 방을 만들거나 기존 방을 복제·편집합니다.
4. Floor, Wall, 2칸 소켓과 필요한 오브젝트를 구성합니다.
5. `6. 맵 미리보기`에서 실제 조립 결과를 생성합니다.
6. `5. 검증·저장`에서 전체 검증을 통과시킨 뒤 저장합니다.

처음에는 같은 테마의 기존 방을 복제해서 구조를 확인하는 방법을 권장합니다.

## 맵 길이와 방 개수를 바꿀 때

1. Room Piece Editor의 `6. 맵 미리보기`를 엽니다.
2. 선택 테마의 생성 프로필을 불러옵니다.
3. Seed, 방 개수, 최소 복도 길이, 방 크기 반영 비율과 난수 폭을 조절합니다.
4. 여러 Seed로 생성 성공과 가독성을 확인합니다.
5. 채택할 값이면 `현재 미리보기 설정을 테마에 적용`을 누릅니다.

미리보기만 생성하면 실제 테마 데이터는 바뀌지 않습니다. 적용 버튼을 눌렀을 때만 `DungeonGenerationProfileSO`가 갱신됩니다.

## 이동 슬롯을 실제 씬에 연결할 때

1. Room Piece Editor에서 이동 슬롯을 넣은 방을 검증·저장합니다.
2. `4. 오브젝트 > 이동 연결·연출 편집기 열기` 또는 `Tools > Dungeon > Procedural Travel Binding Editor`를 엽니다.
3. 이동 Endpoint가 생성될 절차 복도 씬과 `DungeonRoomBuilder`를 선택합니다.
4. Room, Slot, `SceneConnectionSO`, A/B Side를 선택합니다.
5. 현재 Side의 출발 방향 사용 여부와 실제 이동 방향의 전환 연출 프로필을 확인하고 `현재 씬 Builder에 바인딩 추가/갱신`을 누릅니다. `ArrivalOnly`에서는 반대 Side에서 현재 Side로 들어오는 방향의 연출을 편집합니다.
6. 편집기가 자동 저장하지 않으므로 대상 게임플레이 씬을 직접 저장합니다.

`ArrivalOnly` 도착점은 반대 방향 Connection도 비활성으로 두어 단방향을 이중으로 보장합니다.

## 설치 메뉴

| 메뉴 | 용도 |
| --- | --- |
| `Install Boss Theme Procedural Corridor Scenes` | 세 테마 기본 방·씬·프로필·이동 구성을 전체 재설치·검증 |
| `Install Boss Theme Generation Profiles Only` | 생성 프로필만 찾거나 연결 |
| `Install Procedural Corridor Travel Configuration` | HUB 왕복과 보스 이동 연결만 재설치. 폐기된 복도 간 토관 방은 다시 등록하지 않음 |
| `Slime NPC Room > Install Procedural Content` | 공사·순간이동 NPC 에셋을 갱신하되 현재 생성 라이브러리와 필수 방에서는 봉인 |
| `Apply Current Designer Feedback Migration` | 토관·Slime NPC 봉인과 전투 방의 진행도 기반 몬스터 스폰 프로필을 한 번에 반영 |
| `Install Lobby Procedural Corridor Gate Staging Objects` | 기존 HUB 게이트의 위치·활성 상태는 보존하고, 없는 게이트만 비활성 배치용으로 생성 |

> 설치 메뉴는 제작 툴의 일반 저장 버튼이 아닙니다. 팀 작업 중에는 현재 Git 변경분과 열려 있는 씬을 확인한 뒤 실행하세요.

## 안전 규칙

- 방 제작 작업 공간은 저장되지 않는 additive 씬입니다.
- 방 샘플의 모든 출입구는 Wall로 막아 둡니다.
- 미리보기는 실제 게임플레이 프리팹을 실행하지 않습니다.
- 현재 봉인된 토관·Slime NPC 방은 라이브러리와 필수 방 목록에 다시 넣지 않습니다. 재사용 결정 전까지 에셋만 보존합니다.
- 새로 만들어진 HUB 게이트는 기획자가 위치와 구성을 확인한 뒤 직접 활성화합니다. 기존 활성 게이트는 설치기가 끄지 않습니다.
- 최종 판정은 해당 절차 복도 씬의 Play Mode에서 합니다.
