# 05. 반드시 포함할 방과 NPC

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 반드시 포함할 방이란

NPC, 숏컷, 퀘스트, 씬 이동처럼 한 맵에 정확히 한 번 필요한 확장 방입니다. 테마 생성 프로필의 `반드시 포함할 방` 목록에 등록합니다.

- 일반 랜덤 후보와 별도로 한 번만 배치됩니다.
- 등록은 추가 방식이어야 하며 기존 필수 방을 지우면 안 됩니다.
- 다른 테마의 방, 중복 참조, 유효하지 않은 소켓은 생성 실패 원인이 됩니다.

## 현재 필수 방 목록

### Shadow

- `Shadow_Event_TravelToSlime`
  - Slime으로 가는 상호작용 토관
  - Start에서 최소 그래프 거리 3 이상인 먼 위치 우선

### Dragon

- `Dragon_Event_TravelToSlime`
  - Slime으로 가는 상호작용 토관
  - Start에서 최소 그래프 거리 3 이상인 먼 위치 우선

### Slime

- `Slime_Event_ConstructionShortcut`
  - 길을 뚫는 공사 NPC
  - 그래프의 사이클 우회 팔에 배치
  - 정확히 두 연결 소켓이 코너를 이루어야 함
- `Slime_Event_TeleportRemote`
  - 순간이동 NPC
  - Start에서 그래프 거리 4 이상인 먼 막다른 방에 배치
- `Slime_Event_ArrivalFromShadow`
  - Shadow 토관의 도착 전용 방
- `Slime_Event_ArrivalFromDragon`
  - Dragon 토관의 도착 전용 방

## NPC를 분리한 이유

공사 NPC와 순간이동 NPC를 한 방에 모으면 탐색 역할이 겹칩니다.

- 공사 NPC는 지름길의 의미가 생기는 사이클 위치에 둡니다.
- 순간이동 NPC는 이동 보상이 체감되도록 Start 반대편의 먼 위치에 둡니다.
- 순간이동 도착지는 `Slime_Start`의 던전 범위 앵커로 연결됩니다.
- 도착 이동은 기존 물에서 튀어나오는 연출을 재사용합니다.

## 편집 시 주의

- 필수 방의 Room Id와 Slot Id를 임의로 변경하지 않습니다.
- 방 모양을 바꿀 때 필수 그래프 배치 조건을 만족할 소켓을 유지합니다.
- NPC 프리팹 내부의 대화·기능 참조를 방 빌더에 하드코딩하지 않습니다.
- 전체 설치기를 재실행해도 네 Slime 필수 방이 모두 유지되는지 확인합니다.
