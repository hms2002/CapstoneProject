# 10. 통합 테스트 체크리스트

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

구현 완료 여부와 실제 플레이 품질은 별개입니다. 설치기 실행 뒤 아래 순서대로 한 런 전체를 확인합니다.

## 맵 생성

- [ ] Shadow, Dragon, Slime이 각각 목표 15개 방으로 생성된다.
- [ ] Start에서 Boss까지 이동 가능한 경로가 있다.
- [ ] 방·복도가 서로 겹치지 않고, 플레이어가 타일 밖으로 빠질 틈이 없다.
- [ ] 연결된 2칸 소켓만 열리고 사용하지 않은 소켓은 벽으로 막힌다.
- [ ] 큰 ㄴ자·ㄱ자 방과 가변 길이 복도가 정상 배치된다.
- [ ] 각 테마 생성 프로필에 올바른 복도 장식 프로필이 연결되어 있다.
- [ ] Right/Left 연결은 Horizontal, Up/Down 연결은 Vertical 모듈만 사용한다.
- [ ] 짧은 길이부터 긴 길이까지 모듈이 범위를 벗어나거나 겹치지 않고 조합된다.
- [ ] 같은 축·길이·Seed·연결 번호는 같은 모듈 순서를 재현한다.
- [ ] Start와 End가 문 인접 셀까지 의도대로 칠하며, 통행을 막는 장식이나 문을 가리는 타일이 없다.
- [ ] Landmark 수가 프로필 최대값을 넘지 않으며 0개인 결과도 오류로 처리하지 않는다.
- [ ] 현재 필수 방 목록이 비어 있으며 봉인된 토관·Slime NPC Event 방이 생성되지 않는다.

## 전투와 보상

- [ ] 전투 방 안쪽에 진입한 뒤 문이 닫힌다.
- [ ] 전투 방에 진입하기 전에는 해당 방 몬스터가 생성되지 않는다.
- [ ] 다른 방의 몬스터가 플레이어를 미리 인식하지 않는다.
- [ ] 배치한 Warrior/Mage/Tank 지점마다 현재 보스 처치 수에 맞는 Common Melee/Ranged/Tank 몬스터가 생성된다.
- [ ] 스테이지 고정 몬스터 지점은 보스 처치 수와 관계없이 지정한 Enemy 프리팹을 생성한다.
- [ ] 역할별 생성 수와 위치가 방 제작 툴에서 배치한 내용과 일치한다.
- [ ] 전투 잠금 중 문에 상호작용해도 열림 애니메이션이 재생되지 않고 통과할 수 없다.
- [ ] 모든 대상 몬스터 처치 후 방 문이 열린다.
- [ ] 잠금 해제된 문은 열림 애니메이션 이벤트 유무와 관계없이 즉시 통과할 수 있다.
- [ ] Kill Lock 상자는 기존 연출과 함께 해제된다.
- [ ] 제물 보상 방의 내부 문과 보상 상자가 정상 동작한다.

## HUB와 보스

- [ ] 각 이동 방의 Room/Slot 바인딩이 올바른 Connection A/B Side와 현재 씬을 가리킨다.
- [ ] 모든 출발 방향에 의도한 전환 연출 프로필이 연결되어 있다.
- [ ] HUB의 세 게이트가 올바른 테마 복도로 이동한다.
- [ ] HUB→복도와 복도→HUB에서 같은 와이프 전환이 재생된다.
- [ ] HUB→복도 이동 후 해당 테마 BGM으로 전환된다.
- [ ] 사망 후 HUB 복귀 시 HUB BGM으로 복구된다.
- [ ] 복도 Start 방으로 돌아왔을 때 플레이어 위치와 방향이 자연스럽다.
- [ ] Boss 포털이 올바른 보스 씬으로 이동한다.
- [ ] 해당 런에서 이미 처치한 보스는 재진입이 차단되고 안내 팝업이 표시된다.
- [ ] HUB의 기존 상호작용 포탈이 일반 테마가 아니라 고정 DemonkingCorridor 휴식 씬으로 이동한다.
- [ ] DemonkingCorridor의 기존 포탈이 DemonKing 보스 씬으로 이동한다.
- [ ] 폐기된 ProceduralDemonkingCorridor와 이전 두 Connection 방향으로는 진입할 수 없다.

## 봉인 콘텐츠

- [ ] Shadow·Dragon 라이브러리와 생성 프로필에 Slime행 토관 방이 없다.
- [ ] Slime 라이브러리와 생성 프로필에 토관 도착 방이 없다.
- [ ] Slime 라이브러리와 생성 프로필에 공사·순간이동 NPC 방이 없다.
- [ ] Slime Start 방에 이전 순간이동 도착 Endpoint가 남아 있지 않다.

## 맵 보존

- [ ] 복도→HUB→같은 복도로 돌아와도 방 배치와 시드가 유지된다.
- [ ] 처치한 몬스터와 획득한 상자 상태가 지원 범위 안에서 복원된다.
- [ ] 새 런 시작과 런 종료 시 이전 런의 복도 상태가 초기화된다.

## 테마

- [ ] 각 복도에 올바른 타일·진행도 기반 몬스터·보상 오브젝트가 사용된다.
- [ ] Shadow에서 시야 제한과 어둠 기믹이 정상 동작한다.
- [ ] 세 테마의 문과 포털이 배경에 묻히지 않는다.
- [ ] 복도 모듈의 여덟 레이어와 GroundProp이 테마에 맞고 가로·세로 방향에서 올바르게 회전한다.
