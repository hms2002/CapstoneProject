# 04-1. 복도 장식 모듈과 완성본 미리보기

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 무엇을 만드는 기능인가

방의 배치와 두 방 사이 복도 길이는 기존 맵 생성기가 결정합니다. 복도 장식 시스템은 그 결과를 바꾸지 않고, 결정된 2칸 폭 직선 복도에 테마별 짧은 타일·오브젝트 조각을 조합합니다.

`DungeonGenerationProfileSO → CorridorDecorationProfileSO → CorridorDecorationModuleSO`

- 생성 프로필은 테마 장식 프로필 하나를 참조합니다.
- 장식 프로필은 문 앞 안전 여백, Landmark 최대 수, 사용할 모듈 목록을 가집니다.
- 모듈은 역할, 길이, 여덟 타일 레이어와 `GroundProp` Pivot 배치를 가집니다.
- 장식 데이터가 없거나 일부 길이를 채우지 못해도 기본 Floor/Wall 복도는 유지됩니다.

## 툴 열기

Unity 메뉴에서 `Tools > Dungeon > Corridor Decoration Editor`를 엽니다.

1. `테마 생성 프로필`을 선택합니다.
2. 연결된 `복도 장식 프로필`을 확인합니다.
3. 새 프로필을 만들었다면 `생성 프로필에 연결`을 누릅니다.
4. 모듈 ID, 역할과 길이를 입력하고 `새 복도 조각 만들기`를 누릅니다.
5. 검증을 통과한 뒤 `새 모듈 저장 및 프로필 등록`을 누릅니다.

기존 모듈은 프로필 목록의 `편집` 또는 `모듈 직접 선택`으로 불러옵니다. 수정한 원본은 `현재 모듈 갱신 및 프로필 등록`을 눌러야 바뀝니다.

## 제작 좌표

모듈은 항상 왼쪽에서 오른쪽인 `+X` 방향으로 제작합니다. 실제 복도의 상·하·좌·우 변환은 런타임 빌더가 담당합니다.

| 항목 | 규칙 |
| --- | --- |
| 진행 길이 | `x = 0 .. Length - 1` |
| Floor 통로 | `y = 0, 1` |
| Wall | `y = -1, 2` |
| 전체 허용 범위 | 모든 타일과 Prop Pivot은 `x = 0 .. Length - 1`, `y = -1 .. 2` 안에 배치 |
| 타일 레이어 | `UnderFloor`, `Floor`, `FloorDetail`, `GroundDecoration`, `Wall`, `WallDetail`, `Foreground`, `OverlayFX` |
| 오브젝트 | 현재 `GroundProp`만 지원 |

레이어 버튼으로 Tilemap을 선택한 뒤 Unity Tile Palette로 그립니다. `Floor`와 `Wall`을 칠한 셀은 기본 복도 타일을 교체하고, 나머지 장식 레이어는 위에 합성됩니다.

오브젝트는 완성된 프리팹을 `중앙 셀에 GroundProp 추가`로 놓은 뒤 Scene View에서 옮깁니다. 저장 기준은 프리팹 이미지 중앙이 아니라 Transform Pivot입니다. Collider와 동작은 프리팹 설정을 그대로 사용합니다.

## 모듈 역할

| 역할 | 용도와 선택 방식 |
| --- | --- |
| `Start` | 첫 문 안전 여백 다음의 시작 조각. 공간이나 후보가 없으면 생략 |
| `Middle` | 복도 본문의 일반 반복 조각 |
| `Landmark` | 본문 후보 중 무작위로 선택되는 강조 조각 |
| `Filler` | 남은 길이를 채우는 짧은 조각 |
| `End` | 반대편 문 안전 여백 직전의 종료 조각. 공간이나 후보가 없으면 생략 |
| `Short` | 안전 여백을 제외한 길이와 정확히 일치할 때 다른 조합보다 우선 |

`복도당 Landmark 제한`은 최대 개수입니다. Landmark는 Middle/Filler와 같은 후보군에서 선택되므로 0개가 나올 수 있습니다. 임의의 남은 길이를 안정적으로 채우려면 1칸 Filler를 최소 한 개 등록하는 것이 좋습니다. 후보에는 별도 가중치가 없습니다.

## 문 앞 안전 여백

`문 앞 안전 여백`은 양쪽 끝에서 장식 모듈을 배치하지 않을 셀 수입니다.

- 전체 복도 길이에 포함됩니다.
- 미리보기에서는 빨간 반투명 셀로 표시됩니다.
- 통행을 막는 `GroundProp`을 이 영역에 두지 않습니다.
- 복도가 너무 짧으면 전체 길이의 절반을 넘지 않도록 자동 제한됩니다.

## 완성 복도 미리보기

같은 창의 `완성 복도 미리보기`에서 입력 길이에 맞춘 실제 조합을 확인합니다.

| 입력 | 의미 |
| --- | --- |
| 전체 복도 길이 | 두 소켓 사이 전체 셀 수. 양쪽 문 앞 안전 여백 포함, 1~512 |
| 미리보기 Seed | 런타임 레이아웃 Seed 재현값 |
| 연결 번호 | 런타임 연결 목록 인덱스. 길이·Seed와 함께 모듈 순서를 결정 |

`완성본 생성/갱신`을 누르면 비저장 작업 공간의 아래쪽에 +X 완성 복도가 나타납니다. 모듈 ID, 사용 셀 범위, 문 A/B, 안전 여백과 실제 선택 순서를 함께 확인할 수 있습니다.

이 기능은 한 복도의 장식 조합을 보는 미리보기입니다. 방 그래프, 실제 소켓 연결과 모든 복도를 함께 보려면 Room Piece Editor의 `동적 생성 미리보기`를 사용합니다. 두 미리보기 모두 원본 에셋과 게임플레이 씬을 변경하지 않습니다.

## 제공 예제

Shadow, Dragon, Slime 테마에는 프로필 한 개와 다음 여섯 예제가 연결되어 있습니다.

- `Start_02`
- `Middle_03`
- `Landmark_04`
- `Filler_01`
- `End_02`
- `Short_02`

데이터 위치는 `Assets/_Project/Data/Dungeon/CorridorDecorations/{Theme}/`입니다. Shadow Landmark는 묘비, Dragon은 부서진 룬 기둥, Slime은 배럴 계열 `GroundProp` 예시를 사용합니다.

## 예제 설치와 검증

| 메뉴 | 용도 |
| --- | --- |
| `Tools > Dungeon > Examples > Install Theme Corridor Decoration Examples` | 세 테마 예제 생성·갱신 및 생성 프로필 연결 |
| `Validate Theme Corridor Decoration Examples` | 프로필 3개와 모듈 18개의 참조·범위 검증 |
| `Validate Completed Corridor Previews` | 서로 다른 길이로 세 테마 완성 복도 조립 검증 |

설치기는 같은 경로의 예제 에셋을 갱신합니다. 예제를 직접 수정해 실제 콘텐츠로 사용 중이라면 다시 실행하기 전에 변경 내용을 별도 모듈로 복제합니다.

## 저장 전 확인

- [ ] 생성 프로필과 장식 프로필의 테마가 같다.
- [ ] 모듈이 장식 프로필 목록에 등록되어 있다.
- [ ] 모든 타일과 GroundProp Pivot이 허용 범위 안에 있다.
- [ ] 1칸 Filler 또는 의도한 빈 기본 복도 정책이 있다.
- [ ] 여러 길이·Seed·연결 번호에서 완성본을 확인했다.
- [ ] 문 앞 안전 여백에 통행 방해 요소가 없다.
- [ ] 실제 Play Mode에서 가로·세로 복도의 회전 결과를 확인했다.
