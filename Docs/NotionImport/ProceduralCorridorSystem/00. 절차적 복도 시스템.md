이번에 추가하거나 크게 수정한 섹션은 `🆕 2026-09-02 업데이트` 블록으로 표시합니다. 새 기능의 전체 흐름은 [복합 오브젝트 방별 세부 배치](<./03-1. 복합 오브젝트 방별 세부 배치.md>)에서 확인할 수 있습니다.

## 한눈에 보기

- HUB에서 Shadow, Dragon, Slime 세 일반 보스 테마 복도로 진입합니다.
- 각 복도는 준비된 방 데이터를 15개 방 그래프로 조립합니다.
- Start 방은 HUB 왕복, Boss 방은 해당 보스 씬 진입을 담당합니다.
- 복도 간 토관 이동은 랜덤 맵 구조와 맞지 않아 현재 생성 대상에서 제거했습니다.
- Slime 공사·순간이동 NPC 방은 기획 보류로 봉인되어 현재 생성되지 않습니다.
- 전투 방의 몬스터는 방 입장 시 생성됩니다. 공통 역할 지점은 StageMonsterSet으로 진행도별 종류를 고르고, 스테이지 고정 지점은 지정 프리팹을 그대로 사용합니다.
- 제물 보상 Alcove 같은 복합 Prop은 내부 기능을 프리팹에 유지하면서 자식 위치·회전·크기만 방마다 재정의할 수 있습니다.
- 가변 길이 복도는 테마별 짧은 장식 모듈을 조합하며, 입력 길이·Seed·연결 번호로 완성 모습을 미리 볼 수 있습니다.
- 같은 런에서는 방문한 복도의 맵 구성과 지원되는 오브젝트 상태를 보존합니다.
- 최종 DemonKing은 HUB의 기존 상호작용 포탈에서 선택하며 고정 휴식 씬 `DemonkingCorridor`를 거칩니다.
