# 03-1. 복합 오브젝트 방별 세부 배치

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

> 🆕 **2026-09-02 신규 문서** — 방별 복합 Prop 배치의 기획자 작업 순서, 영향 범위와 기술 계약을 설명합니다.

## 목적

`SacrificeRewardAlcove`처럼 제물 동상, 잠긴 보상 문과 상자가 하나의 기능 프리팹을 이루는 경우 내부 참조는 유지하면서 방마다 공간 배치만 다르게 만들 수 있습니다.

현재 표준 슬롯은 다음과 같습니다.

| 표시 이름 | Slot Id | 대상 |
| --- | --- | --- |
| 제물 동상 | `OfferingStatue` | 제물 상호작용 오브젝트 |
| 보상 문 | `RewardDoor` | 제물 성공 후 열리는 내부 문 |
| 보상 상자 | `TreasureChest` | 내부 보상 상자 |

## 기획자 작업 순서

1. `Tools > Dungeon > Room Piece Editor`에서 대상 Treasure 방을 열거나 복제합니다.
2. `4. 오브젝트`에서 Alcove Prop의 일반 Transform으로 전체 위치를 맞춥니다.
3. 카드의 `복합 오브젝트 세부 배치`에서 수정할 슬롯의 `이 방에서 자세 재정의`를 켭니다.
4. 저장할 채널만 `위치 적용`, `회전 적용`, `크기 적용`으로 켭니다.
5. 숫자를 입력하거나 `Scene View에서 대상 선택` 후 Transform 핸들로 조정합니다.
6. 전체 검증 후 방을 저장하고 다시 열어 복원 여부를 확인합니다.
7. 절차 복도 Play Mode에서 제물 상호작용, 문, 상자와 Collider를 함께 확인합니다.

## 영향 범위

- 카드의 일반 Transform: Alcove 전체를 현재 방에서 이동합니다.
- 자식 Pose 재정의: 선택한 슬롯·채널만 현재 `RoomTemplateSO`에 저장합니다.
- 프리팹 기본값: 재정의하지 않은 슬롯과 채널에 사용됩니다.
- Prefab Mode 수정: 같은 프리팹을 쓰는 모든 방의 공통 기본값을 바꿉니다.

따라서 한 방만 바꿀 때는 프리팹을 수정하지 않습니다. 예를 들어 동상의 위치만 켜면 그 방의 동상 위치만 고정되고 문과 상자, 동상의 회전·크기는 프리팹 기본값을 계속 따릅니다.

## 저장과 검증 규칙

- Slot Id가 비었거나 중복되면 저장할 수 없습니다.
- 방 데이터의 Slot Id가 현재 프리팹에 없으면 저장과 런타임 빌드가 실패합니다.
- 프리팹 슬롯이 허용하지 않은 채널은 재정의할 수 없습니다.
- Scale 재정의의 어떤 축도 0이면 안 됩니다.
- `이 방에서 자세 재정의`를 끄면 저장값을 제거하고 프리팹 기본 자세로 되돌립니다.
- 자식 Sprite와 Collider가 방 벽·문·다른 자식을 침범하는지는 Play Mode에서 최종 확인합니다.

## 복도 장식 GroundProp과의 차이

이 기능은 Room Template 안의 복합 Prop용입니다. `Corridor Decoration Editor`의 GroundProp은 복도 모듈 원점 기준으로 프리팹 전체 Pivot·회전·크기만 저장하며 내부 자식 Pose 편집 UI는 제공하지 않습니다.

복도 장식에서 같은 내부 변형이 반복해서 필요하다면 변형별 완성 프리팹을 만들거나, 별도 요구사항으로 모듈 데이터 계약을 확장합니다.

## 기술 슬롯을 갱신할 때

`Tools > Dungeon > Update Sacrifice Reward Alcove Pose Slots`는 기존 Alcove 프리팹의 수동 자식 Transform을 유지하면서 위 세 슬롯 계약을 설치·갱신합니다. 일반 방 저장 작업에는 이 메뉴가 필요하지 않습니다.

새 복합 프리팹은 `RoomCompositePoseAuthoring`에 안정적인 Slot Id, 표시 이름, 대상 Transform과 허용 채널을 등록합니다. 툴과 빌더는 특정 프리팹 이름이 아니라 이 계약을 읽습니다.
