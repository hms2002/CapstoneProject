# 04. 맵 생성 설정과 미리보기

[← 시작 페이지](<./00. 절차적 복도 시스템.md>)

## 생성 프로필

Shadow, Dragon, Slime은 각각 하나의 `DungeonGenerationProfileSO`를 사용합니다.

| 값 | 현재 기본 의미 |
| --- | --- |
| 방 개수 | Start와 Boss를 포함해 15개 |
| Seed | 같은 후보·정책·설정에서 같은 결과 재현 |
| 방당 최대 배치 시도 | 겹치지 않는 물리 배치를 탐색하는 한도 |
| 최소 복도 길이 | 모든 연결이 확보할 최소 길이 |
| 방 크기 반영 비율 | 큰 방일수록 간격을 늘리는 정도 |
| 복도 길이 난수 폭 | Seed 기반 가변 길이 범위 |
| 레이아웃 정책 | 그래프 거리, 분기, 사이클과 역할 수 제약 |
| 반드시 포함할 방 | 해당 맵에 정확히 한 번 배치할 Event 방 |

현재 세 프로필은 최소 복도 길이 `2`, 방 크기 반영 비율 `0.05`, 난수 폭 `2`를 사용합니다.

## 그래프 정책

공통 탐험 정책은 다음 범위를 목표로 합니다.

- Start→Boss 그래프 거리: 6~8
- 의미 있는 분기: 2~4
- 사이클: 1~2
- Treasure: 최소 1개
- Combat: 최소 4개

필수 Event 방이 많아지면 생성기는 요청한 15개 안에서 해당 방을 먼저 확보한 뒤 나머지 역할을 채웁니다.

## 동적 맵 미리보기

미리보기는 실제 조립기를 사용해 다음 항목을 확인합니다.

- 방 선택과 직사각형 예약 충돌
- 그래프 거리, 분기와 사이클
- 연결 소켓과 복도 길이
- 실제 Floor/Wall 타일 결과
- 오브젝트와 이동 슬롯 표식

공통 몬스터 역할은 `W/M/T`, 스테이지 고정 몬스터는 `S`, 이동 슬롯은 `EI`(Interaction), `ET`(Trigger), `EA`(ArrivalOnly)로 표시됩니다. Door, Monster 스폰, Kill Lock, 상호작용과 씬 이동은 실행하지 않습니다.

## 실제 테마에 적용

`현재 미리보기 설정을 테마에 적용`은 다음 값을 프로필에 저장합니다.

- Seed
- 방 개수와 Boss 포함 여부
- 배치 시도 수
- 레이아웃 정책
- 최소 복도 길이
- 방 크기 반영 비율
- 복도 길이 난수 폭

복도 타일 오버라이드는 미리보기 전용입니다. 런타임 타일 팔레트는 각 테마 씬의 `DungeonRoomBuilder`가 소유합니다.

## 권장 검증 방법

1. 대표 Seed를 하나 기록합니다.
2. 랜덤 Seed를 최소 5회 확인합니다.
3. 큰 ㄴ자·ㄱ자 방과 모든 필수 방이 들어가는지 확인합니다.
4. 실패 시 방 개수만 늘리기 전에 소켓 방향, 예약 크기와 복도 설정을 확인합니다.
5. 적용 뒤 실제 절차 복도 씬을 다시 로드해 다음 생성부터 값이 반영되는지 확인합니다.
