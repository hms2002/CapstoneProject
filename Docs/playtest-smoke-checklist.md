# Playtest Smoke Checklist

이 문서는 Unity 에디터 플레이 모드 기준으로 빠르게 확인하는 스모크 테스트 체크리스트다.
목표는 "구조 변경 이후 핵심 흐름이 실제 플레이에서 깨지지 않는지"를 짧은 시간 안에 확인하는 것이다.

## 범위

- 허브 진입과 기본 UI 동작
- 설정 UI
- 입력 리바인딩과 글리프 반영
- 월드 상호작용 프롬프트
- 무기 툴팁 입력 힌트
- 보스 씬 진입 후 대화 -> 전투 시작 흐름

## 추천 시간

- 1차 스모크 테스트: 10~15분
- 문제 재현 포함 확인: 20~30분

## 시작 전 준비

- Unity Console 비우기
- `ProtoTypeHub`에서 시작
- Game 뷰 해상도는 최소 2개 이상 확인
- 가능하면 아래 4개 비율을 한 번씩 본다
  - 16:9
  - 16:10
  - 4:3
  - 21:9

## 1. 허브 진입

- `ProtoTypeHub`를 연다
- 플레이를 시작한다
- 허브 진입 직후 오류가 발생하지 않는지 본다
- 전역 UI가 정상적으로 표시되는지 본다

기대 결과:

- 콘솔에 치명적인 에러가 없다
- 허브에서 플레이어 조작이 가능하다
- 상호작용 가능한 오브젝트 앞에서 프롬프트가 뜬다

## 2. 설정 UI

- 설정 UI를 연다
- 창 모드와 해상도 스테퍼가 정상적으로 동작하는지 본다
- 해상도 목록이 `가로 -> 세로` 순으로 보이는지 확인한다
- `16:9`, `16:10`, `4:3`, `21:9`를 각각 한 번씩 적용해본다

기대 결과:

- 16:9는 레터박스가 없다
- 16:10, 4:3은 상하 letterbox가 생긴다
- 21:9는 좌우 pillarbox가 생긴다
- UI가 레터박스 바깥으로 새지 않는다

## 3. 입력 리바인딩

- 키매핑 UI를 연다
- `Interact`를 아래 중 2개 이상으로 바꿔본다
  - `E`
  - `Backspace`
  - `Space`
  - `LeftControl`
  - 마우스 버튼
- `Skill1`, `Skill2`도 한 번씩 바꿔본다

기대 결과:

- 키매핑 UI에 글리프가 정상 표시된다
- 아이콘이 없는 키만 텍스트 fallback으로 보인다
- 긴 키도 레이아웃을 깨지 않는다

## 4. 월드 상호작용 프롬프트

- 상점 NPC, 상호작용 오브젝트, 포탈 등 앞에 서본다
- `Interact`를 1칸 키와 긴 키로 각각 바꿔가며 본다

기대 결과:

- 프롬프트 아이콘이 현재 바인딩 기준으로 바뀐다
- `Backspace`, `Enter`, `Ctrl`, `Space` 같은 긴 키도 텍스트를 침범하지 않는다
- 아이콘과 텍스트가 자연스럽게 한 줄에 배치된다

## 5. 무기 툴팁 입력 힌트

- 인벤토리나 무기 상세 UI를 연다
- 무기 스킬 설명 블록을 확인한다
- `Skill1`, `Skill2` 바인딩을 바꾼 뒤 다시 툴팁을 확인한다

기대 결과:

- 무기 툴팁의 입력 힌트가 현재 바인딩 기준으로 바뀐다
- 글리프가 있으면 아이콘이 보이고, 없으면 텍스트 fallback이 나온다

## 6. 보스 씬 흐름

- 보스 씬으로 진입한다
- 보스가 즉시 공격하지 않는지 본다
- 진입 후 대화가 먼저 시작되는지 본다
- 대화 종료 후 전투가 시작되는지 본다

기대 결과:

- 보스는 대화 전에는 비전투 상태다
- 대화가 끝난 뒤에만 전투가 시작된다
- 드랍/처치 처리는 실제 보스 사망 시점에만 발생한다

## 7. 저장과 씬 이동

- 설정을 하나 바꾼다
- 다른 씬으로 이동했다가 돌아온다
- 가능하면 게임을 다시 실행한 뒤도 본다

기대 결과:

- 설정값이 의도대로 유지된다
- 해상도/창 모드/UI 스케일/스크린 셰이크가 예상대로 남아 있다
- 씬 이동 후 전역 UI가 중복 생성되지 않는다

## 기록 템플릿

문제가 나오면 아래 형식으로 짧게 남긴다.

```text
[심각도] 기능명
- 재현 절차:
- 실제 결과:
- 기대 결과:
- 관련 씬:
- 스크린샷/로그:
```

심각도 예시:

- `치명적`: 진행 불가, 씬 진입 불가, 전투/대화 막힘
- `높음`: 핵심 기능 오작동
- `중간`: 불편하지만 진행 가능
- `낮음`: 정렬, 표현, 텍스트 문제

## 1차 권장 순서

아래 순서로 보면 가장 빠르다.

1. 허브 진입
2. 설정 UI 해상도/창 모드
3. 키 리바인딩
4. 월드 프롬프트
5. 무기 툴팁
6. 보스 씬

## 이번 라운드 집중 포인트

- 해상도와 레터박스
- 입력 글리프 반영
- 긴 키 글리프 레이아웃
- 보스 대화 후 전투 시작 흐름
