Scope: [npc-run-affection-dialogue](../ActiveTasks/npc-run-affection-dialogue.md). User approved implementation after discussing the loop, then supplied the final animated indicator during inspection. No edits were lost through that interruption.

### Result

- During an active run Sasha offers one affection conversation per NPC ID. Success adds affection; a completed failure does not change affection but consumes the conversation. New merchant objects in later stages share the same session record.
- Subsequent interactions use short, choice-free greetings, with full-backpack reactions taking priority. Hub interactions use greetings. Maximum affection disables affection conversations and the indicator.
- Existing active-run end/reset behavior clears opportunities; existing permanent progress commit behavior is preserved. Boss/commander and unconfigured-NPC routes remain unchanged.
- Opted-in run conversations start through player interaction, rather than the profile-once automatic room introduction.
- Six affection conversations (two each for amounts 0/1/2) and five greetings (three ordinary, two full-backpack). Thirty new localized strings are connected in all five existing languages.
- Temporary reward thresholds 1/2/3 reuse the first 20% discount effect, producing 20%/40%/60% total. Final reward design remains deferred.
- The supplied PNG is preserved byte-for-byte (SHA256 `6be91e2257edf4c9668f8b17fabdeac8e4591abdad460e81b6c0b29b52fc0f6a`). Unity slices it left-to-right into three 32x32 frames. The authored renderer animates at 4 fps by default, at 0.8 world units.

## Sasha's Permanent Merchant Rewards And World Price Tags

Scope: [merchant-affection-rewards](../ActiveTasks/merchant-affection-rewards.md). The user approved the recommended two-line world price presentation and specified four permanent tiers. This replaces the temporary three-discount configuration in the earlier entry.

### Result

| Affection tier | Cumulative permanent benefit |
| --- | --- |
| 1 | One random unsold visible item per stock receives an additional integer 10–20% discount. Selection and percentage stay fixed through reentry/repricing, including after the special item sells; refreshing stock can select a new offer. |
| 2 | Defeat/TimeOver commits up to 100 held gold as a profile credit. The next run consumes and flushes it once before publishing the starting balance. Victory/Abort create no new credit. |
| 3 | Eligible Rare/Epic relic candidates use relative weights 1.10/1.15 versus Common 1.00. This affects new rolls and preserves category, unlock, exclusion and dedicated-consumable-slot rules. |
| 4 | All merchant goods receive 5% global affection discount. Multiply global and special factors from the original price and round once; 1,200 with 5% and 20% costs 912. |

Saved affection is the permanent entitlement source; pending run gains participate immediately. Existing affinity-three profiles receive tiers 1–3 automatically and can converse to reach the new maximum of four. Two candidates at amount three reuse the existing high-affection Ink knots. Donation box and other NPC content remain excluded.

The existing slot prefabs now contain authored OriginalPriceText and SpecialOfferTag labels. Discounted goods show original strikethrough plus payable price; special goods add a yellow badge/accent above the item. Sold/empty goods hide supplemental labels. Existing stock, purchase currency and item acquisition owners remain intact. The user-adjusted merchant/bubble placement is preserved byte-for-byte.
