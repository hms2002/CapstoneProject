# Art Folder Guide

Art contains visual source and runtime visual assets that are not prefabs.

Suggested sprite grouping:

- `Sprites/Player`
- `Sprites/NPCs`
- `Sprites/Monsters`
- `Sprites/Bosses`
- `Sprites/Items`
- `Sprites/UI`
- `Sprites/Map`
- `Sprites/VFX`

Materials, shaders, and tilemap art are grouped separately.

Do not move tile palette or atlas-related assets until importer, atlas, and tilemap renderer
settings are verified together.
